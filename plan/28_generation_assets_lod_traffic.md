# 生成設定・距離LOD・大量交通

2026-09-16。調整値の置き場所、描画の簡略化、建物発着の交通についての現行仕様。

## 生成設定

`App/assets/generation/` の分野別JSONを `GenerationSettings` が一度読み、地形・河川・集落・町割・郊外・農地・建物・森林・道路・鉄道・地名・交通量へ渡す。値の正本をC++側に重複させない。必須値、未知キー、数値型、整数性、範囲、関連する最小値と最大値を検査する。

変更後は再起動して新規生成する。実行中の再読込と既存セーブの移行は対象外。設定の一覧・単位・編集方法は [assets内の説明](../App/assets/generation/README.md)。型と範囲の正本は `GenerationSettings.def`、編集用JSON Schemaはそこから生成する。ワールドの配列容量、ハッシュ、ベジェ式、誤差許容、モデルの頂点設計などの実装定数は区別する。

## 距離LOD

全88個の元OBJに中景・遠景モデルを用意し、`assets/lod/` に元パスの階層を保って格納する。原点・向き・実寸を維持し、材質と画像参照を検証する。

| 対象 | 描画 |
|---|---|
| 建物 | 250m未満は元モデル、それ以遠は中景。チャンクの境界全体が850mより遠ければ遠景を材質別に結合 |
| 自動車・工事車両 | 近・中・遠のモデル。通常車は100m/350mで切り替え、遠方は256台ずつ変換行列をGPUへ渡す |
| 歩行者 | 100m以内は手足と歩行姿勢、100〜1000mは24三角形の人体を256人ずつ一括描画 |
| 電車 | 180m/700mで車両LODを切り替える |
| 信号機 | 80m/200mでLODを切り替え、500mより遠ければ描かない。灯器名・点灯状態を維持 |
| 標識支柱 | 通常標識80m/200m、案内標識120m/300m。板は最小の面形状を共有 |
| 駅・車庫 | 手続き生成モデルから簡略メッシュを作り、500m以遠で使う |
| 樹木・道路・パーツ・軌道 | 距離別の既存簡略形状と材質バッチを使い、遠景の細かい枝葉・枕木等を省略 |

距離は立体距離を使う対象を明示して判定し、俯瞰の真下にある車・建物が不必要に近景扱いにならないようにする。小さい箱・板など、元から最小形状のモデルは共有する。車両の遠景は無テクスチャの車体・窓・車輪とし、毎フレーム頂点をCPUで作り直さない。近景の影・信号の点灯は維持する。

## 建物前の発着と渋滞

`BuildingAccessIndex` が実在する接道建物を索引化する。農地・公園・未建築区画は発着点にせず、供用中の地上道路にある、建物側の端の通行可能車線を選ぶ。交差点直近や接道距離の長すぎる建物は除外する。新規開発・撤去はチャンクを巡回して反映し、道路変更では索引を再構築する。

通常交通は建物前で停止状態から出発し、有向車線接続で到達可能な別の建物前を目的地にする。目的車線も指定して経路探索し、最後は建物前で減速して到着扱いにする。通常交通は敷地内を曲がって駐車する経路や駐車台数を管理しない。歩行者の乗換に使う車には、別途共用車在庫と目的地の駐車枠を管理する。[歩行者仕様](30_pedestrian_spec.md)。バスは既存の停留所経路を使用する。

標準設定は全体上限12,000台、補充240台/秒・1回の蓄積上限64台。人口・用途・時間帯が交通需要を決める。注視点の周囲1,800mでは接道建物数×0.65、最大2,400台を優先する。道路の混雑や建物不足で目標に届かない場合は、重ねて出現させず空きを待つ。

画面外でも車間・信号・合流・交差点を同じように計算する。画面外になったことを理由に時間だけで先へ送ったり、需要超過を理由に車列を消したりしない。Active/Dormantは表示対象の分類であり、渋滞を計算するかどうかの区別ではない。

`LaneVehicleIndex` は毎フレーム車線・交差点内経路ごとに車を並べ、前後車を二分探索する。車線変更先と同フレームの交差点進入先も予約し、車間は車体長を引いた距離で判定する。経路返信の適用は車両ID索引を使う。走行状態や経路を逐一出す車両ログは廃止し、明示的なテスト実行時に限り集計値を保存する。

## 常設検証

- `GenerationSettings`: 必須値・型・範囲・未知値・関連値の矛盾、外部編集の読み込み。
- `TrafficScaling`: 索引と総当たりの一致、建物発着と到達、画面外の12,000台の停止車列。
- `ModelLod`: 全OBJの寸法と材質、通常描画とのGPU比較、256台の区切りをまたぐ変換、12,000台の描画と空フレーム。
- `Rendering.SignalDistanceAndCost`: LOD切替後も500mの境界では表示し、その外側で消す。

実機測定の条件・結果は `artifacts/traffic_lod_config/REVIEW.md` に記録する。

## 詳細モデルの先読みと塗装（2026-09-17）

樹木は地表の高さを含む256mタイル境界まで600mで詳細表示する。原型・近景・遠景モデルをGPU上で共有し、配置情報は初回表示時に地形とは独立して生成・公開する。LODの往復では地形・植生の再生成やモデル再転送を行わない。高標高を理由に詳細を無効化しない。道路は曲線の最近点まで1200mで詳細表示し、標示・沿道設備を1700mで先に準備する。

乗用車と軽自動車は `assets/vehicles/paint.json` の10色を使用する。IDから決めた同じ色を近・中・遠景へ渡し、遠景の色変更でバッチ数を増やさない。`RuralVisual` で切替距離・高山・長い道路・全3LODの車体色を検証する。

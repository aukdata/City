# 地名データ仕様書

## 現行の行政区分表記

規模に応じて日本語の市・町・村、英語の City / Towm / Vill. を付ける。Towmはユーザー指定。ローマ字の読み語幹は先頭を大文字にして保存し、表示時に共通の SettlementNames で付加する。旧セーブの小文字の読みも読込時に変換する。地図・俯瞰・住所の表記を共通化する。駅名の「駅」は二重に付加しない。以下には地名形成の設計例も含む。現行操作は [06](06_ui_spec.md)、生成変更は [33](33_generation_and_underground.md)。


マップ生成時にシード値から確定的に地名を生成する。
地形タイプに依存した語根辞書を使い、集落を起点として道路・駅・IC名を派生させる。

---

## 1. 設計方針

- **シード値固定**: 同じシード値なら同じ地名が生成される（再現性あり）
- **地形依存**: 集落の立地する地形タイプから語根カテゴリを選ぶ
- **集落起点**: 集落が「地名の親」。道路・駅・施設名はすべてここから派生
- **重複排除**: 同一マップ内で同じ地名が出ないよう生成時にチェック

---

## 2. 語根辞書

地形タイプ（`03_procedural_generation_spec` の4種）に対して優先する語根カテゴリを割り当てる。

### カテゴリ定義

```cpp
enum class PlaceCategory : uint8 {
    River,      // 川・水系
    Mountain,   // 山・丘・高地
    Plain,      // 平野・田・原
    Coast,      // 海・湾・浜
    General,    // 地形に依らない汎用
};
```

### 語根リスト

各語根は「前節」と「後節」に分かれ、組み合わせて地名を作る。

```
[前節] ← 地名の個性を決める部分
  River系:   瀬、渡、沢、洗、湊、津、江
  Mountain系: 高、岩、根、尾、峰、古、御
  Plain系:   広、大、長、新、細、小、上、下
  Coast系:   磯、鳴、白、浦、崎、角、荒
  General系: 飯、松、梅、桜、鈴、亀、甲、竹、千、三

[後節] ← 地形語。地名らしさを与える部分
  River系:   川、瀬、橋、田（みずた）、渕、浜
  Mountain系: 山、丘、台、坂、谷、森、峠、野
  Plain系:   野、田、原、平、畑、里、村
  Coast系:   浜、港、崎、磯、湾、津、島
  General系: 本、中、東、西、南、北（方位は単独では使わず前節と組み合わせ）
```

> 前節・後節の組み合わせで2〜4文字の地名を生成する。
> 例: 前節「飯」＋後節「松」→「飯松」、前節「高」＋後節「丘」→「高丘」

### 地形タイプ別カテゴリ重み

| 地形タイプ | River | Mountain | Plain | Coast | General |
|-----------|-------|----------|-------|-------|---------|
| 山間盆地 | 30% | 40% | 10% | 0% | 20% |
| 沿岸平野 | 15% | 5% | 30% | 30% | 20% |
| 河川扇状地 | 40% | 10% | 30% | 0% | 20% |
| 丘陵台地 | 10% | 40% | 20% | 0% | 30% |

## 3. 地名生成アルゴリズム

### 集落地名の生成

```cpp
String generateSettlementName(int settlementId, TerrainType terrain, uint64 mapSeed) {
    // 集落ごとに独立したシード
    uint64 seed = hashCombine(mapSeed, settlementId);
    RNG rng(seed);

    // 地形に応じたカテゴリ重みから前節・後節のカテゴリを選ぶ
    PlaceCategory cat = weightedPick(terrainCategoryWeights[terrain], rng);

    // 前節・後節をカテゴリ内からランダム選択
    String prefix = pick(prefixList[cat], rng);
    String suffix = pick(suffixList[cat], rng);

    String name = prefix + suffix;  // 例: "飯松"

    // 重複チェック: すでに生成済みの地名と衝突したら suffix を変える
    while (usedNames.contains(name)) {
        suffix = pick(suffixList[cat], rng);
        name = prefix + suffix;
    }
    usedNames.insert(name);
    return name;
}
```

### 派生地名の生成ルール

集落名（例: 「飯松」）を基に、以下のルールで施設名・道路名を自動生成する。

```
集落名: S とする

駅名:
  単一集落を通る路線: 「{S}駅」
  中心的な駅:        「{S}中央駅」「{S}市駅」
  端末駅:            「{S}口駅」「新{S}駅」

IC名:
  「{S}IC」「{S}東IC」「{S}西IC」

道路名（04_gameplay_detail_spec の自動命名ルールに準拠）:
  国道・バイパス: 「{S}バイパス」「{S}街道」
  生活道路:      「{S}〇丁目」「{S}通り」

信号所名:
  「{S}信号場」
```

## 4. 地区名・字名

集落の中を細分化する「字（あざ）」レベルの地名。建物情報パネルや道路情報パネルに表示される。

```cpp
struct Aza {
    int     id;
    String  name;       // 例: "本町" "駅前" "北区" "○○丁目"
    Rect2   bounds;     // 地区の矩形範囲（マップ座標）
};
```

### 字名の生成

```
集落の中心から方位・機能で命名する:

  中心部:   「本町」「中央」「元町」
  駅周辺:   「駅前」「駅東」「駅西」
  方位:     「東町」「西町」「南町」「北町」
  丘・台地: 「○○台」「○○丘」（前節に集落名を使う）
  田畑地帯: 「○○田」「○○野」

丁目:
  市街地セル密度が高い字は「一丁目」「二丁目」と分割する
  最大5丁目まで
```

## 5. 地名の表示

### 表示スケール

カメラのズームレベルに応じて表示する地名の粒度を変える。

| ズームレベル | 表示する地名 |
|------------|-------------|
| 広域（チャンク4枚以上） | 集落名のみ |
| 中域（チャンク1〜4枚） | 集落名 + 主要道路名 |
| 近接（チャンク1枚以内） | 字名・丁目 + 建物名 |

### フォント・スタイル

```
集落名:  ゴシック体 太字  白文字（黒縁）
字名:    ゴシック体 中字  白文字（薄縁）
道路名:  細字      グレー背景プレート風
駅名:    丸囲み    路線カラー
```

## 6. データ構造（ランタイム）

```cpp
struct PlaceNameDB {
    // 集落 ID → 集落地名
    HashMap<int, String> settlementNames;

    // 施設 ID → 施設名（駅・IC・信号所）
    HashMap<int, String> facilityNames;

    // 道路計画 ID → 道路名
    HashMap<int, String> roadNames;

    // 字 ID → 字名
    HashMap<int, Aza>    azaMap;

    // 重複管理
    HashSet<String> usedNames;

    // 生成
    String getOrCreate(int entityId, EntityType type, ...);
};
```

> `PlaceNameDB` はマップ生成時に一度構築し、セーブデータに永続化する。
> 道路新設時は `roadNames` に追記するだけ。

## 7. 手動リネーム

プレイヤーがすべての地名を変更できる。

```
対象: 集落名・字名・道路計画名・駅名・路線名
操作: 右パネルの名前欄をダブルクリック → テキスト入力
制限: 最大10文字、空文字不可
変更後: PlaceNameDB を更新。HUD・情報パネルに即時反映
```

> 集落名・字名を変更しても、すでに生成された派生地名（道路名・駅名など）はそのまま残る。
> 派生地名を変えたい場合はそれぞれ個別にリネームする。

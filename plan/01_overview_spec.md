# 概仕様書 - 日本の街づくり交通シミュレーター

## ゲームコンセプト

**タイトル（仮）**: バイパス建設日誌 / 国道バイパス計画

**ジャンル**: 街づくり＆交通シミュレーション（サンドボックス）

**エンジン**: Siv3D v0.6.16 (C++)

**テーマ**: 平成〜令和の日本。旧来の旧街道ベースの国道が交通渋滞で飽和し、バイパス・環状道路の整備によって街が発展していく様子を描く。

---

## ゲームプレイの核心

### メインゲームループ

1. 街は自然に発展し、人口・交通量が増加する
2. 旧道（国道・県道）が渋滞で飽和する
3. プレイヤーが道路・建物を整備して渋滞を解消する
4. 解消により税収増・発展が加速 → さらなる渋滞が生まれる…（繰り返し）

### 交通システム（最重要）

- 車両がリアルタイムで経路探索して走行する（AIベースの交通流）
- **渋滞の発生要因**:
  - 旧道（狭い・信号多い・交差点複雑）への交通集中
  - 商業施設・駅周辺の駐車待ち
  - 災害（土砂崩れ、冠水）による通行止め
  - イベント（祭り・花火大会）による歩行者増加・交通規制
  - 工事による車線減少
- **解消手段**:
  - バイパス建設
  - 交差点の立体化・ロータリー化
  - 信号のタイミング調整
  - 公共交通機関の整備（バス路線、駅）
  - 駐車場の新設

### 道路計画システム

- **計画モードと着工を分離**: 計画は無料でいつでも作成・破棄できる
- **計画名の自動命名**: 起点・終点の地名頭文字から自動生成（例: 「飯松バイパス」「甲諏自動車道」）
  - プレイヤーが自由に変更可
- **計画一覧パネル**: 未着工・工事中・完成済みの計画を一覧管理
- **着工タイミングはプレイヤーの判断**: 資金・渋滞状況・工事の交通影響を見極めて決断する
- **部分開通**: 完成した区間から順次開通。全線開通を待たずに効果が出る

### 建設時間システム（重要）

- **道路・施設の建設にはゲーム内時間がかかる**
  - 工事期間中は該当道路の車線が減少（片側交互通行など）
  - 拡幅工事も同様に工事期間中は通行に支障が出る
- **リダンダンシー（冗長性）の戦略的重要性**
  - 幹線の工事前に迂回路・バイパスを整備しておく必要がある
  - 準備なしに工事を始めると、迂回路のない渋滞が発生し街が麻痺する
  - プレイヤーは「どの順番で」「どこを先に」整備するかの計画が求められる
- **工事の可視化**
  - 工事中の道路には工事車両・ガードレール・カラーコーンが表示される
  - 工事進捗率をUIで確認できる
  - 一時停止中でも工事は進まない（ゲーム時間に連動）

## ゲームシステム

### 進行方式
- **リアルタイム進行**
  - 一時停止（スペースキー）
  - 早送り（1x / 2x / 4x）
- **ゲーム内時間**: 1分 ≈ リアル数秒、朝・昼・夕・夜のサイクルあり
- **季節**: 春夏秋冬あり（雪・台風など季節イベントに影響）

### 経済システム
- **資金のみ**（木材・食料等の資源なし）
- 収入源：
  - 住民の固定資産税・住民税
  - 商業施設からの売上税
  - 観光収入（観光資源の整備で増加）
- 支出：
  - 建設・道路工事費
  - 公共施設の維持費
  - 公共交通の運行費

### ゲームモード
- **サンドボックス**: 資金無限・目標なし（自由建設）
- **通常モード**: 初期資金あり、資金管理しながら街を発展させる

## 視点・カメラ

### 通常視点（メイン）
- **3D見下ろし型**（斜め45〜60度のアイソメトリックに近い視点）
- マウスドラッグで回転、スクロールでズームイン・アウト
- WASDでカメラ移動

### 一人称視点
- 任意の場所でキーを押して切り替え
- 実際に道路を走行しているような視点（車・歩行者目線）
- 交通渋滞の雰囲気を体感するための演出モード

## 建造物カテゴリ

自動生成される建物（ゾーン依存）と、プレイヤーが任意に建設するインフラに分類する。詳細は `05_zoning_spec.md` 参照。

### ゾーン自動生成される建物（11種）

| 種別 | 建物 |
|------|------|
| 住宅系 | 戸建て住宅・低層マンション・中層マンション・高層マンション |
| 商業系 | 店舗（コンビニ〜SC）・オフィスビル |
| 産業系 | 工場（中小工場〜物流センター） |
| 農業系 | 農地 |

### プレイヤーが任意建設するインフラ

| 種別 | 具体物 |
|------|--------|
| 公共施設 | 学校・病院・役所・消防署（公園含む） |
| 交通インフラ | 道路各種・信号機・駐車場・バス停・駅 |
| 緑地 | 公園・緑地帯 |

### 道路種別
- 生活道路（1〜2車線・歩道なし）
- 県道（2車線・歩道あり）
- 国道（4車線・歩道あり）
- バイパス（4車線・立体交差）
- 高速道路

## 住民・歩行者

- 市民は**数値**として管理（人口・幸福度・通勤時間など）
- 歩行者は3Dオブジェクトとして画面上に存在するが**個体識別なし**
- 車両はAIで経路探索して走行（個体識別あり、渋滞計算に使用）
- バス・トラックなど複数の車両タイプが存在

## 舞台設定・世界観

- **時代**: 平成初期〜令和（1990年代〜2020年代）
- **地形**: 日本的な地形（山・川・田んぼ・住宅地が混在）
- **景観の変化**:

## 決定済み追加仕様

### ゾーニングシステム
- **ビットマップ型ゾーニング**（グリッドセルに用途地域を塗るペイント操作）
- 日本の**都市計画法の用途地域**を簡略化した区分を採用
- ゾーン種別ごとに建設可能な建物・密度が決まる（詳細は `05_zoning_spec.md`）
- ゾーン内に建物が自動生成・発展・老朽化する
- 道路アクセスのないセルは発展しにくい（需要スコアが低くなる）
- 市街化区域 / 市街化調整区域の2層構造を持つ

### 地形変更
- 地形の掘削・盛土が可能
- 山の切り通し・トンネル建設によるバイパス建設
- 川への橋梁・暗渠工事
- 造成費用がかかる（斜度・地質による）

### マップ開始状態
- **既成市街地スタート**: ゲーム開始時から旧道・家屋・商店街が存在
- 旧来の街道網が既に渋滞気味の状態から始まる
- プレイヤーはゼロから建設するのではなく、既存インフラを活かしつつ改良する

---

### 車両・交通AI
- 同時走行台数: **数百台**（軽快動作重視）
- 各車両が**個別にAI経路探索**して走行
- 前方の車両・信号に応じてリアルタイムに停車・発進

### 道路の形状
- **3次ベジェ曲線**で任意の曲線道路を建設可能
- 曲線の制御点をドラッグして形状を調整

### マップ・地形
- **プロシージャル生成**（毎回ランダムな地形）
- **チャンクシステム**（Minecraftライク）: マップを固定サイズのチャンクに分割し、必要な範囲のみロード・描画

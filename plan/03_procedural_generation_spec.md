# プロシージャル生成仕様書

## 概要

ゲーム開始時にシード値と地形タイプからマップを生成する。
生成物は「既成市街地（旧道＋集落）をもつ平成初期の日本の小さな町」。

---

## 1. 生成パラメータ（開始画面）

| パラメータ | 入力方式 | 説明 |
|-----------|---------|------|
| シード値 | 整数入力 or ランダムボタン | 乱数の種、同じシードなら同じマップ |
| 地形タイプ | 4択ボタン | 下記参照 |

---

## 2. 地形タイプ

### タイプA: 山間盆地（さんかんぼんち）
```
・四方を山に囲まれた盆地
・中央に川が流れ、川沿いに平野が広がる
・旧街道は川に沿って縦断する
・バイパス候補: 山の切り通し or 盆地外周の迂回路
```
```
[山] [山] [山] [山]
[山] [平] [平] [山]
[山] [平] [川] [山]  ← 旧道は川沿いを縦断
[山] [平] [平] [山]
[山] [山] [山] [山]
```

### タイプB: 沿岸平野（えんがんへいや）
```
・片側が海、反対側が山地
・海岸線沿いに旧街道、港町が核になっている
・漁港・観光地の要素あり
・バイパス候補: 山際の新道 or 海岸埋立
```
```
〜〜〜〜〜〜〜〜〜〜  ← 海
[港] [平] [平] [平]
[平] [平] [平] [丘]  ← 旧道は海岸線に沿う
[丘] [丘] [山] [山]
```

### タイプC: 河川扇状地（かせんせんじょうち）
```
・山から流れ出る複数の川が合流する扇状地
・川の分岐・合流が多く、橋が重要インフラになる
・水害・冠水イベントが起きやすい
・バイパス候補: 川の上流側の高台ルート
```
```
    [山]
   /    \
[川]   [川]   ← 複数の川筋
  \    /
  [合流] [平野]
```

### タイプD: 丘陵台地（きゅうりょうだいち）
```
・緩やかな丘が連続する地形
・丘の上に集落、谷に田んぼが広がる
・旧道は丘の稜線に沿う（昔からの道）
・バイパス候補: 谷を貫く新道（トンネル or 高架）
```
```
[丘] [谷] [丘] [谷]
[集] [田] [集] [田]  ← 集落は丘の上
[丘] [谷] [丘] [谷]
```

## 3. 地形生成アルゴリズム

### Step 1: 高さマップ生成

```
1. Perlinノイズ（多重オクターブ）で基本高さマップを生成
   - オクターブ数: 6
   - 周波数: 地形タイプにより調整
   - 振幅減衰: 0.5

2. 地形タイプ別マスクを乗算
   - 山間盆地: 中央を凹ませるラジアルグラデーション
   - 沿岸平野: 片側を低く傾けるランプ関数
   - 河川扇状地: 中央から広がる扇型の傾斜
   - 丘陵台地: 中周波ノイズを強調

3. 高さ値を離散化
   - h < 0.1  → 水域（海・湖）
   - h < 0.2  → 低地（氾濫原・河川敷）
   - h < 0.5  → 平野
   - h < 0.7  → 丘陵
   - h >= 0.7 → 山地
```

### Step 2: 河川生成

```
1. 山地の高点から水を流す（流水シミュレーション）
   - 各セルから最も低い隣接セルへ流れる
   - 流量が閾値を超えたセルを河川としてマーク

2. 河川の浸食処理
   - 河川セルの高さをわずかに下げる
   - 河川沿いに低地（氾濫原）を形成

3. 河川幅
   - 流量に応じて1〜4セル幅
```

### Step 3: 地表種別の決定

| 高さ | 勾配 | 水域 | → 地表種別 |
|------|------|------|-----------|
| 低地 | - | あり | 水域（河川・湖） |
| 低地 | 緩 | なし | 水田・湿地 |
| 平野 | 緩 | なし | 農地・草地 |
| 平野〜丘 | 緩 | なし | 宅地適地 |
| 丘〜山 | 急 | なし | 林地・山林 |
| 山 | 急 | なし | 岩地 |

## 4. 集落配置アルゴリズム

### Step 1: 集落の核（コア）を決定

```
1. 各チャンクのパスファインダーグリッドで地形適性スコアを計算:
   score = elevation_suitability × slope_bonus

   elevation_suitability:
     h < 50m  → 1.0（低地・平野）
     h < 200m → 0.7（丘陵下部）
     h < 500m → 0.3（中山間地）
     h >= 500m→ 0.1（高地）

   slope_bonus（周囲3×3の最大傾斜）:
     < 3%  → 1.0（平坦）
     < 5%  → 0.8
     < 10% → 0.5
     >= 10%→ 0.0（不適地）

2. スコア > 0 の候補セルをスコア降順でソートし、
   ポアソンディスクサンプリング（最小間隔 2800m）で集落核を配置
   → 高スコアの平坦・低地が優先的に採用される

3. 64×64 チャンク（65km×65km）で約9000〜10000集落を生成

4. 種別割り当て:
   - CastleTown（城下町）: score >= 0.6 かつ既存CastleTownから20km以上離れた地区
   - PostTown（宿場町）: CastleTownから6km以内の地区
   - Village（農村）: それ以外
```

### Step 2: 集落の内部レイアウト生成

集落種別ごとに道路パターンを分岐して生成する。

```
1. 共通: extractKaido() で集落中心付近の街道（Arterial/LocalRoad）を抽出
   - 中心ノードの対向エッジを起点に両方向へ直進追跡
   - 中心付近の方向ベクトル dirAtCenter を基準軸として使う

2. CastleTown（城下町）
   - 50m（町人地）/80m（武家地）の二層格子
   - 中央 60m 角を城広場としてエッジ生成をスキップ
   - 格子エッジの 5〜15% を間引き（両端ノード次数 >= 2 を維持）
   - 街道中央部を 2 回分割してクランクを形成

3. PostTown（宿場町）
   - 街道を主軸に、垂直路 3〜5 本を等間隔に配置
   - 片側または両側に裏通り（40〜60m オフセット）を生成
   - 裏通り端を街道両端へ接続して閉ループ化

4. Village（農村）
   - 街道中央付近の 1〜2 エッジを分割
   - 法線方向へ 60〜120m の短い袋小路支線を生成（櫛状）
   - 傾斜 10% 超・水面（y < 0.5）はスキップ
```

### Step 3: 集落規模の決定

| 種別 | 面積 | 建物密度 | 主要施設 |
|------|------|---------|---------|
| 城下町 (CastleTown) | 500〜800m級 | 高 | 駅・役場・商店街・病院 |
| 宿場町 (PostTown) | 200〜400m級 | 中 | 小学校・郵便局・商店 |
| 農村 (Village) | 100〜200m級 | 低 | 農家・小規模集会所 |

## 5. 旧道ネットワーク生成

集落間を繋ぐ旧道を **3層の分岐構造** で生成する。

### Layer 1: 幹線街道（CastleTown間チェーン）

```
1. CastleTown 地区のみで Prim's MST を計算
2. MST上の最長パス（diameter）を求める → メイン街道チェーン
   - BFS 2回で tree diameter を抽出
3. diameter チェーン上の連続ペアを A* で接続
   - RoadType: Arterial（4車線）
4. diameter に含まれない CastleTown → MST上の親（diameter上の CastleTown）へ枝線接続
```

### Layer 2: 地方道（PostTown → 幹線への分岐）

```
1. 各 PostTown 地区に対して、最寄りの幹線街道中間ノードを検索
   - 空間ハッシュ（バケットサイズ200m）で O(1) 検索
2. 最寄りノードから PostTown へ A* パスファインディング
   - forbiddenGoalDirs に幹線の接線方向を設定 → 自然な Y字分岐
   - RoadType: Arterial（2車線）
3. 幹線から5km以上離れた PostTown → 最寄りの接続済み PostTown へ接続
   - RoadType: LocalRoad（2車線）
```

### Layer 3: 集落道（Village → 最寄り道路ノード）

```
1. Layer 1+2 の全中間ノードで空間ハッシュを構築
2. 各 Village 地区に対して:
   - 距離 < 300m → 「街道沿い」扱い（道路生成不要）
   - 距離 >= 300m → 分岐道路を A* で生成
     - RoadType: LocalRoad（2車線）
     - forbiddenGoalDirs で Y字分岐を誘導
3. 全 Village 集落を必ず接続する（孤立集落は禁止）
```

### A* 経路探索（全Layer共通）

```
コスト = 距離 × 勾配ペナルティ × 地形ペナルティ

勾配ペナルティ:
  slope < 5%  → ×1.0（平坦）
  slope < 15% → ×2.0（緩斜面）
  slope < 30% → ×5.0（急斜面）
  slope >= 30%→ ×20.0（ほぼ通過不可）

地形ペナルティ:
  水域（h < 0）→ ×10.0

Y字分岐メカニズム:
  1. 分岐道路は既存の中間ノード（約120m間隔）に接続
  2. forbiddenGoalDirs で幹線接線方向へのアプローチを回避
  3. ポスト処理 spreadIntersectionTangents が交差点ベジェを自動調整
```

### 街道の種別

```
CastleTown ↔ CastleTown（メインチェーン・枝線）→ Arterial（4車線）
幹線ノード → PostTown                            → Arterial（2車線）
PostTown → PostTown（遠距離接続）                → LocalRoad（2車線）
道路ノード → Village                             → LocalRoad（2車線）
```

### Step 4: 橋の自動生成

```
街道が河川を横断する箇所に橋を自動生成
橋の仕様:
  川幅 < 10m  → 単純橋（コンクリート）
  川幅 < 30m  → 桁橋
  川幅 >= 30m → プレートガーダー橋
```

## 6. 初期建物の配置

### 配置ルール

```
各集落の格子ブロックに対して:
  道路に面したブロック辺 → 建物を配置（確率的）

  確率は密度と用途に応じて:
    城下町の幹線沿い: 商業 70% / 住宅 30%
    城下町の裏通り:   住宅 80% / 空地 20%
    宿場町の幹線沿い: 住宅 60% / 商業 30% / 空地 10%
    農村:             農家 70% / 空地 30%
```

### 建物の外観（昭和〜平成初期）

| ゾーン | 建物タイプ | 外観 |
|-------|-----------|------|
| 商店街 | 木造2階建て店舗 | 昭和の商店街 |
| 住宅地 | 木造一戸建て | 瓦屋根・庭付き |
| 農村 | 農家 | 大きな屋根・農地付き |
| 幹線沿い | ロードサイド店舗（少量） | ガソリンスタンド・食堂 |

### 初期公共施設の配置

```
城下町に必ず配置:
  ・駅（ローカル線）× 1
  ・市役所 or 町役場 × 1
  ・病院 × 1

宿場町に配置:
  ・小学校 × 1
  ・郵便局 × 1

農村に配置:
  ・農協 × 1（任意）
```

### 初期鉄道設定

§6 で配置した「ローカル線の駅」に対し、最小限の鉄道設備を自動生成する。

```
① 駅間を結ぶ TrackEdge を最短経路（地形コスト考慮の A*）で生成
   軌間: 狭軌 1067mm、非電化
② RailLine を1路線生成（路線名は PlaceNameDB から自動付与）
③ 初期編成を1本生成（2両編成・ディーゼル気動車）
   → 最寄りの Depot に配備（Depot がなければ始発駅に簡易基地を生成）
④ 1日 4往復の基本ダイヤを自動生成
   始発 6:00、最終 22:00 を均等割り
⑤ 単線・1閉塞区間として Block を設定
```

## 7. 初期ゾーン自動設定（Phase 6）

旧市街地周辺のセルに初期ゾーンを自動割当てる。

### 割当ルール

```
旧市街地（集落 settlement）の中心から 300m 以内:
  → 道路沿い密度が高いセル: 商業地域（Commercial）
  → それ以外: 住居地域（Residential）
集落中心から 300〜600m:
  → 低層住居地域（LowResidential）
農地地表（surfaceType == Farm）:
  → 農業地域（Agricultural）
それ以外（草地・森林・未開発）:
  → 未指定（Unzoned）
```

### 市街化区域フラグ

```
集落中心から 600m 以内のセル → urbanArea = true
それ以外 → urbanArea = false（市街化調整区域）
```

## 8. 初期交通状態（Phase 5）

生成直後から渋滞が発生している状態にする。

```
初期車両配置:
  各道路区間に「飽和率」を設定
    幹線国道: 70〜90%（すでに混んでいる）
    県道:     40〜60%
    生活道路: 10〜30%

車両は初期位置から目的地（ランダムな集落）へ向けて走行開始
→ ゲーム開始直後から幹線に車が集中して渋滞が発生
```

## 9. 生成の再現性・バリエーション

```
同一シード値 + 同一地形タイプ → 完全に同じマップを生成
シード値が違うと:
  ・地形の形状が変わる
  ・集落の位置・数が変わる
  ・街道のルートが変わる

地形タイプが違うと（同一シードでも）:
  ・地形の骨格が変わる（山の位置・川の流れ）
  ・集落種別の傾向が変わる（沿岸なら港町、盆地なら城下町的）
```

---

## 10. チャンクとの統合

```
生成データはチャンク単位で保持:
  各チャンクは生成時に以下を受け取る:
    ・高さマップ（HeightMap）のそのチャンク分
    ・道路グラフのうちそのチャンクに属するエッジ・ノード
    ・建物リスト
    ・ゾーンマップ（初期ゾーンは Phase 6 で自動設定）

遅延生成:
  カメラが接近したチャンクのみ詳細メッシュを生成
  遠距離チャンクは高さマップのみ保持（LOD）
```

## 11. 生成フロー全体

```
[開始画面]
  シード値 + 地形タイプを入力
        ↓
[Phase 1: 地形生成]         ~数十ms
  Perlinノイズ → 高さマップ
  河川生成
  地表種別決定
        ↓
[Phase 2: 集落配置]         ~数ms
  核コア決定（ポアソンディスク）
  種別判定（CastleTown/PostTown/Village）
  種別別レイアウト生成（城下町/宿場町/農村）
        ↓
[Phase 3: 旧道生成]         ~数十ms
  最小全域木で幹線決定
  A*で地形考慮の経路探索
  橋の自動生成
        ↓
[Phase 4: 建物・施設配置]   ~数十ms
  密度マップに従って建物を配置
  公共施設を確定位置に配置
        ↓
[Phase 5: 交通初期化]       ~数ms
  車両を道路上に配置
  渋滞初期状態のセットアップ
        ↓
[Phase 6: 初期ゾーン自動設定] ~0.05秒以内
  旧市街地周辺のセルに初期ゾーンを自動割当て
        ↓
[ゲーム開始]
```

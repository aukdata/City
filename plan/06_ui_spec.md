# UI・操作の現行仕様

2026-09-15。実装: `GameScene_Input.cpp`、`GameScene_RoadPlan.cpp`、`Camera`、`WorldMapView`、`PanelManager`、`UIRenderer`。旧構想は [旧UI案](unused/06_ui_proposal_2026-04.md) に保存した。この文書は実装済み操作を記載する。

## 視点と移動

| 操作 | 入力 |
|---|---|
| 前後左右 | WASD。斜めの徒歩移動は正規化 |
| 俯瞰の回転 | 中ボタンドラッグ |
| 俯瞰の平行移動 | Shift＋中ボタンドラッグ |
| 俯瞰のズーム | ホイール |
| 真上の俯瞰 | Numpad 0 |
| 徒歩／俯瞰 | F |
| 徒歩で見回す | 右または中ボタンドラッグ |
| 徒歩速度 | 通常1.5m/s、Shiftで4.5m/s、Ctrlで15m/s。重複時は15m/s |
| 俯瞰の高速移動 | Ctrlで2倍 |

徒歩の目線は足元から1.5m、視野角80度。Fでの切り替えと地図からのジャンプは、そのフレームから新しい視点を使う。道路・線路・トンネルの歩行面は現在の高さに近い面を選び、高架下から橋上や地下から地表へ吸い付かせない。1ステップは0.75m以下。操作の時間刻みは0.1秒以下として、描画停止後の大移動を避ける。

## 自由運転

Cで近くの開通済み道路へ乗車し、再度Cでその場所に降りて徒歩へ戻る。Fでは降車して俯瞰へ戻る。道路計画などの編集パネルを閉じ、未確定の道路計画の点列は保持する。道路がない場合や車体を置けない場合はメッセージを表示する。

| 操作 | 入力 |
|---|---|
| アクセル | W |
| ブレーキ／後退 | S。前進を止めてから0.35秒保持すると後退 |
| ハンドル | A／D。交差点で進路を自由に選ぶ |
| 強ブレーキ | Space |
| 一時停止／再開 | P |
| 見回す | 右または中ドラッグ。離すと前方へ戻る |
| 地図／メニュー | M／Esc |

運転中は街と車を等速で進め、1〜3による倍速と編集キーを無効にする。降車時は乗車前の時間速度へ戻す。地図・メニュー・文字入力・アプリの非フォーカス中は車を停止して保持し、地図からのジャンプでは運転を終了する。保存のショートカット中も加減速しない。

右側の運転席は車体中心から右0.35m、路面から1.2m、視野角80度。勾配に合わせて前方を向き、トンネルで地表へ持ち上げない。簡略ダッシュボード、操作に連動するハンドル、km/h、D/R、走行距離、道路の設定速度を表示する。車体・接地・周辺交通の仕様は [09](09_vehicle_spec.md#自由運転の現行実装2026-09-14)。

## 地図

地図は3Dの左手座標系と方位を共通化する。北は−Z、東は−X。進行方向が上のとき、運転席から右に見える道路は地図でも右に表示する。全画面地図も同じ方位を使い、ドラッグ・ズーム・ジャンプは逆変換で求める。

右上はカメラの周囲を追従表示する。初期表示範囲は2km。地図上の＋／−とホイールで500m・1km・2km・4km・8kmへ切り替える。「北が上／進行方向が上」で方位を切り替え、運転・徒歩の向きにも追従する。中央に現在位置と進行方向、左上に北の矢印、左下に縮尺を表示。ボタン操作は地図を開かず、地図本体のクリックで全画面へ移る。


- Mまたはミニマップのクリックで全画面表示。初回はカメラ位置と4倍表示、以後は前回の中心・縮尺を保持する。
- Homeで現在のカメラ位置へ戻る。倍率は維持し、開いていた右クリックメニューを閉じる。
- WASDまたは左ドラッグで移動。WASDは画面上420px/s、Ctrlで3倍。斜めでも同じ速度。
- ホイールはカーソル位置を固定して拡大縮小。＋／−ボタンでも操作できる。倍率1〜512。
- 右クリックで「ここへジャンプ」。決定すると地図を閉じて移動し、車両追跡を解除する。
- Esc、M、閉じるボタンで終了。閉じたフレームも地図が入力を消費し、背後の道路建設やポーズ画面を動かさない。
- 道路・鉄道は全縮尺で表示。画面外だけを除外し、曲線の点数を画素密度に応じて減らす。川、地区界、重なりを避けた地名とローマ字、駅名、カーソル位置の住所を表示。道路・鉄道の土被りがあるトンネル部分は破線で描く。坑口の前後は実線を保つ。
- 表示中心・倍率・サイズ・データが同じときは地形・道路の画像を再利用。地名・現在位置・住所・右クリックメニューは最終UI描画へ分離し、文字用テクスチャをキャッシュ画像へ混在させない。地図の描画設定とクリップ範囲は呼出し元へ復元する。

## 編集モード

| キー | モード | 操作 |
|---|---|---|
| R | 道路計画 | 始点・終点を選択 → 経路生成 → ドラッグ編集 → 確定して着工 |
| Z | 用途と街の開発 | 用途ボタン・0〜6で選択。1区画／小／大ブラシ、需要と開発状況を表示 |
| G | 地形編集 | 地形ブラシ。Ctrl＋ホイールで半径 |
| X | 線路敷設 | 線路ノード・接続の編集 |
| B | バス路線 | 停留所列の編集 |
| V | サンドボックス編集 | サンドボックスのみ。ノード・制御点編集 |
| Ctrl＋R | 敷設デバッグ | サンドボックスのみ。旧即時敷設 |

Escは「入力欄を離れる → 仮計画を破棄 → 編集モード・選択を解除 → ポーズメニュー」の順に処理する。同時に複数の階層を閉じない。

## 現在地と国道の表示

俯瞰・撮影視点では街の中心上空へ地名ビルボードを投影する。都市・町・村の順で優先し、同じ規模では注視点に近いものを優先する。重なる名前、画面外・視点背後、実際の開閉状態のHUDと重なる名前は描かない。距離上限は都市120km・町45km・村15km、最大24件。文字は画面に正対し、日本語の下にローマ字を併記する。市・町・村の接尾辞は集落種別に対応する。

俯瞰ではポインタが指す地表の地名・ローマ字と近傍道路名を、画面左下へ背景なしで表示する。国道ならおにぎり型の国道マークと番号を併記する。HUD・編集パネル・コマンド入力上では表示しない。道路の検索には空間索引を使い、画面移動ごとに全道路を走査しない。配置・寸法は本書末尾の「住所・地名の軽量表示」を参照。

徒歩・運転・追従視点では、注視点に最も近い地区名と読みを上部中央へ1件だけ固定する。国道は80m以内で最も近い開通道路が属する路線を上部に1件表示し、クリックで路線情報を開く。徒歩・運転の前方には地名ビルボードを重ねない。地図内の地名と道路に立つ実物の標識はそれぞれ継続する。

## 道路計画

1. 生活道路・サブ幹線・4車線幹線・一方通行を選ぶ。
2. 地面または既存道路をクリックして始点、終点を選ぶ。この段階では道路を生成しない。
3. 「経路生成」を押す。初期生成の線形探索と共通の `RoadAlignment` で、勾配・曲率を制約に地形・水域・構造費を比較する。探索が選んだ曲線の制御点をプレビュー・Undo/Redo・確定へ引き継ぐ。探索後の再フィットや別の勾配上限で合法な候補を拒否しない。
4. 候補の点をドラッグして移動。線をドラッグすると、その位置に調整点を追加する。移動中は点列のガイドを表示し、離した時点で候補を更新する。編集で勝手にA*探索し直さない。「経路を再生成」は始点・終点から再探索する。
5. 右クリック、Backspace、Ctrl＋Zで戻す。Ctrl＋Y／Ctrl＋Shift＋Zでやり直す。生成前／生成後の状態も復元する。1回のドラッグが履歴1件、最大128件。
6. 延長・費用・工期を確認し、「確定して着工」またはEnterで建設を開始する。通常モードでは資金確認・接続検査を通った候補だけを反映し、費用を支払い、用地内の建物・敷地を撤去する。サンドボックスでは資金確認と支払いを省き、接続・形状・用地の検査は維持する。資金不足・接続失敗なら街を変更せず、候補を保持する。[工事仕様](23_road_construction_spec.md)

既存道路へ12m以内でスナップし、高さが異なる道路は除外する。Altで一時解除。PgUp/PgDnで次に置く・動かす点の高さを変更できる。2m未満の区間や固定端点間で成立しない勾配は拒否する。始点・終点は画面上のラベルと掴める丸印で表示する。

仮計画は独立した道路網。未確定の破棄は本体へ影響しない。パネルを閉じたままの配置は不可。保存→計画一覧から着工という二段階の必須操作を廃止し、計画一覧は既存計画の状態確認・操作に使う。

## 時間、選択、保存

| 操作 | 入力 |
|---|---|
| 一時停止／直前の速度で再開 | Space（運転中はP） |
| 即時停止 | 0（ゾーン編集時を除く） |
| 速度×1／×2／×4 | 1／2／3（ゾーン編集時を除く） |
| ゾーン表示 | Tab |
| ランダム車両の生成 | T |
| セーブ | Ctrl＋Shift＋S、またはポーズメニュー |

建物・道路・車両・畑・水田・住宅敷地をクリックして情報表示する。敷地判定は道路を切り抜いた実描画面を使う。左上の街情報と右上の通知・ミニマップは見出し端の−／＋で折りたたむ。

ポーズメニューはゲームに戻る、セーブ、タイトルへ戻る、終了、効果音量。効果音量は60% → 30% → 消音 → 100%を循環し、起動中のシーン間で保持する。↑↓とEnterまたはクリックで操作できる。ゲームに戻る際はメニューを開く前の時間速度へ戻す。もともと停止中なら停止を保つ。

## 入力の優先順位

右下の操作ガイドは徒歩と俯瞰で切り替わり、徒歩ではShift走行と右／中ドラッグの見回しを表示する。

全画面地図、ポーズ、テキスト入力を、カメラと編集ショートカットより優先する。入力欄でWASDや道路名を入力しても街が移動しない。HUD・パネル上のマウスを地形・道路へ流さない。Ctrl＋Shift＋Sなどのコマンド中もカメラを動かさない。

`KeyboardActions` は通常のキー状態に加え、Windowsのキーイベント番号から短い押下を一度だけ拾う。履歴の再読で同じ操作を繰り返さず、非フォーカス中のイベントを持ち越さない。文字入力とIMEはSiv3Dに任せる。入力欄にフォーカスがある間は `GameInput` 自体が他用途のキーを返さない。Enter・Esc・外部クリックで離れたフレームも入力欄が占有し、残った短い押下を移動や建設に流さない。IME変換のEnterでは欄を閉じず、同じ文字数の置換も路線名へ反映する。

## 用途と街の開発

Zで右側の用途パネルを開く。用途7種のボタン、ブラシ3段階、住宅・商業・工業の需要、開発中・完成・待機理由の件数を表示する。左ドラッグで塗り、Shift+左ドラッグで矩形。Z・Esc・パネルの×で終了。別のツールや運転へ移ると用途パネルを閉じ、塗り入力を受け付けない。

パネル上のクリックは地面へ透過しない。停止中も用途指定は可能で、再開時に開発が進む。数字0〜6は用途選択に使い、速度変更へ重複送信しない。既存建物が残ること、成長に約10〜34秒かかることを画面で案内する。詳しい立地条件・保存は [05](05_zoning_spec.md)。

## 鉄道ダイヤ（2026-09-14）

Hでダイヤを開閉する。路線の新規作成・前後選択、名称、運休、2両普通／4両快速、始発・終発・間隔、停車駅一覧からの選択・追加・削除・並べ替え、駅ごとの停車時間を扱う。時刻と間隔はゲーム内時計で表示。発車予定と実際の走行数・発車待ちを確認できる。

変更は「変更を適用」で反映し、走行中の便は発車時の内容を維持する。入力不正や経路不成立は下書きのまま修正できる。文字入力とポーズ中は背後のゲーム操作から保護する。駅の「地図」と「車庫を見る」で対象へ移動。「始発駅に車庫」で適地検証後に追加する。詳細は [鉄道](10_railway_spec.md)。

## FPSと選択表示（2026-09-17）

F3で左下に直近30秒のFPSグラフを表示・非表示にする。約0.1秒ごとの実フレーム数と経過時間から求め、地図の操作中も切り替えられる。文字入力中とポーズメニュー中は反応させない。F3を押し続けてもカメラ操作を止めない。F3+Rのアセット再読込は維持する。

敷地・田畑と電車の選択は、建物・車と同じ黄色い輪郭を使う。電車は編成の各車体に合わせてクリック判定し、道路に沿う坂道の姿勢も反映する。

## 俯瞰距離とコマンド

俯瞰距離は5〜60000m。地面からの高さを距離×sin(俯角)で決め、高標高でも地面直上へ押し込まない。ホイールは距離×1.12^ノッチ数として、同じ入力の分割・合算で変位を変えず、逆方向の同数入力で元の距離へ戻る（上下限に達した場合を除く）。地域全体を見渡す高度では、64km全域の128m格子LOD地形を表示する。

`/` で左下のコマンドパレットを開く。入力中はゲームのキー操作を遮断し、Tab補完・上下キーの履歴・Enter実行・Esc終了を提供する。FPSグラフは入力中の描画だけを隠して重なりを避ける。[全コマンドと例](28_commands.md)。

## 住所・地名の軽量表示（2026-09-17）

俯瞰でポインタが指している地名・ローマ字読み・道路名は、左下12pxの余白に高さ最大48px、最大幅360pxの2行で表示する。国道番号のおにぎりは30×27px。長い地名は省略し、F3のFPSグラフ表示中はその上へ移す。パレット・メニュー・パネル操作中の入力制御は維持する。徒歩・運転視点の上部表示は変えない。

住所表示、拡大地図・右上地図の地名、俯瞰の街名には塗りつぶし背景を置かない。日本語とローマ字は残し、文字自体の細い縁取りで読みやすさを保つ。地図操作ボタン・縮尺・メニューの背景は操作部として維持する。

# ゲームプレイ詳細仕様書

## 1. ゲーム時間スケール

### 基本速度定義

| 速度設定 | 1ゲーム日 = リアル時間 | 1ゲーム月 | 1ゲーム年 |
|---------|----------------------|----------|----------|
| 一時停止 | ∞ | ∞ | ∞ |
| ×1 | 6秒 | 3分 | 36分 |
| ×2（推奨） | 3秒 | 1.5分 | 18分 |
| ×4 | 1.5秒 | 45秒 | 9分 |

**推奨プレイ速度**: ×2（イベントが2〜3分に1度来るテンポ感）

## 2. 経済システム

### 初期資金・収支

**開始資金**: 30億円

#### 収入（月次）

収入源: 国・県からの交付金（税収ではない）

```
交付金 = 人口 × 交付単価 [億円/人/月]

交付単価（人口規模に応じてステップ変化）:
  人口 0〜5,000人:         0.0008 億円/人/月
  人口 5,000〜20,000人:    0.0010 億円/人/月
  人口 20,000〜50,000人:   0.0012 億円/人/月
  人口 50,000人以上:       0.0013 億円/人/月

交付タイミング: ゲーム内で月初め（1日 0:00）に一括入金

幸福度ボーナス:
  happiness >= 80%: 交付金 × 1.1
  happiness < 40%:  交付金 × 0.8

例: 人口 10,000人・幸福度 70% → 10,000 × 0.0010 = 1.0億円/月
```

**初期交付金（人口15,000人・幸福度70%）**: 約1.5億円/月

#### 支出（月次）

| 支出項目 | 算出方法 |
|---------|---------|
| 道路維持費 | 道路種別ごとの単価 × 総延長（後述） |
| 公共施設維持費 | 施設ごとの固定費（後述） |
| バス路線運行費 | 路線数 × 0.1億円/月 |
| 工事費（分割払い） | 建設中の工事費を工期で按分 |

**初期月次収支**: +1.0億円/月（道路維持費0.4億・施設0.1億を差し引き）

## 3. 建設コスト・時間

### 道路計画〜完成のフロー

```
① 計画モードでルート設計
     ↓ 資金消費なし・いつでもキャンセル無料
② 計画を保存（計画名が自動生成される）
     ↓ 計画一覧に登録
③ プレイヤーが任意のタイミングで「着工」
     ↓ 着工時に費用確定・月払いで引き落とし開始
④ 工期は計画総延長と道路種別から算出
     ↓ 工事中は計画所属の全区間が `UnderConstruction`
⑤ 工期満了時に計画所属の全区間が同時開通
     ↓
⑥ 全区間開通 → 計画完了
```

**着工キャンセル違約金**: 工事費の残額の20%

### 計画名の自動命名

```
起点地名の頭文字 + 終点地名の頭文字 + 路線種別後置語

バイパス   → 「〇〇バイパス」  例: 飯松バイパス
国道改良   → 「〇〇道路」      例: 鈴亀道路
高速道路   → 「〇〇自動車道」  例: 甲諏自動車道
環状道路   → 「〇〇環状線」    例: 松本環状線
```

プレイヤーは確定前に自由に編集可能。

|---------|--------|----------|-------------|------------|
| 生活道路 | 1〜2車線 | 0.5億円 | 0.01億円 | 1ゲーム月 |
| 県道 | 2車線 | 1.5億円 | 0.03億円 | 2ゲーム月 |
| 国道 | 4車線 | 4億円 | 0.08億円 | 4ゲーム月 |
| バイパス | 4車線 | 8億円 | 0.12億円 | 6ゲーム月 |
| 高速道路 | 4車線 | 20億円 | 0.30億円 | 12ゲーム月 |

> 実装メモ（2026-04）: v1 は概算費・工期とも道路種別と総延長ベースで算出し、橋梁・高架・トンネル補正は未導入。

### 道路オプション（追加費用）

| オプション | 追加費/km | 追加期間/km | 備考 |
|-----------|----------|-----------|------|
| トンネル | +15億円 | +12ゲーム月 | 山地通過時 |
| 橋梁 | +8億円 | +6ゲーム月 | 河川・谷越え |
| 高架 | +6億円 | +4ゲーム月 | 立体交差 |
| 歩道整備 | +0.5億円 | +1ゲーム月 | 生活道路・県道向け |

### 道路拡幅（既存道路）

| 拡幅内容 | 費用/km | 建設期間/km | 工事中の状態 |
|---------|---------|-----------|------------|
| 2車線→4車線 | 3億円 | 3ゲーム月 | 片側交互通行（実質1車線） |
| 歩道なし→歩道あり | 0.4億円 | 1ゲーム月 | 路肩工事（速度制限） |
| 信号→立体交差 | 5億円 | 6ゲーム月 | 交差点閉鎖・迂回路必要 |
| 信号→ロータリー | 1億円 | 2ゲーム月 | 交差点閉鎖（短期） |

> **工事中の交通への影響**: 2車線が片側交互通行になると実質容量50%減。渋滞が大幅悪化するため、事前のバイパス整備が必須。

### 施設建設

| 施設 | 建設費 | 月次維持費 | 建設期間 |
|------|-------|----------|---------|
| バス停 | 0.02億円 | 0 | 即時 |
| バス路線開設 | 0.5億円 | 0.1億円/路線 | 1ゲーム月 |
| 駐車場（50台） | 0.5億円 | 0.01億円 | 1ゲーム月 |
| 公園（1ブロック） | 0.3億円 | 0.02億円 | 2ゲーム月 |
| 信号機 | 0.05億円 | 0 | 即時 |
| 駅（新設） | 10億円 | 0.2億円 | 12ゲーム月 |

### 旧道の廃止

- **廃止可能条件**: 並行するバイパスが開通済みであること
- **廃止手続き**: 廃止指定 → 車両が自動的に迂回 → 翌ゲーム月から廃道
- **廃止効果**: 月次維持費の削減のみ（撤去費用の返還なし）
- **廃道後の土地**: ゾーン指定が可能になる（緑地・宅地転用など）

## 4. 建設時間とリダンダンシーの戦略

### 工事中の交通への影響まとめ

| 工事内容 | 影響範囲 | 容量低下 |
|---------|---------|---------|
| 新設（新ルート） | なし（未開通） | なし |
| 拡幅工事 | 工事区間 | 最大50% |
| 交差点改良 | 交差点＋前後100m | 最大70% |
| 橋梁工事 | 橋全体 | 最大80% |
| トンネル掘削 | 掘削口前後 | なし（地下） |

### プレイヤーが意識すべき建設順序の例

```
悪い例（渋滞悪化する順序）:
  国道を拡幅工事 → 片交になり渋滞3倍 → バイパスまだない → 街が麻痺

良い例（リダンダンシーを確保した順序）:
  バイパスを先に建設（新設なので既存交通に影響なし）
  → バイパス開通で交通分散
  → 余裕が出てから旧国道を拡幅工事
  → 拡幅後に旧道の信号整備
```

## 5. 人口成長モデル

### 自然成長

```
月次成長率 = 基本成長率 × 渋滞係数 × 住宅余力係数 × 幸福度係数

基本成長率: +0.3%/月（約3.6%/年）

渋滞係数:
  平均通勤時間 < 15分 → ×1.2（成長促進）
  平均通勤時間 < 30分 → ×1.0
  平均通勤時間 < 45分 → ×0.5
  平均通勤時間 >= 45分 → ×0（成長停止）
  平均通勤時間 >= 60分 → ×-0.3（人口流出）

住宅余力係数:
  住宅充足率 > 80% → ×0.5（住む場所がない）
  住宅充足率 50〜80% → ×1.0
  住宅充足率 < 50% → ×1.3

幸福度係数:
  公園・緑地・観光施設の充足度で0.8〜1.2
```

### 成長の連鎖

```
人口増加
  → 交通量増加 → 渋滞悪化 → 成長鈍化
  → 交付金収入増加 → 建設資金が増える
  → 商業需要増加 → 商業ゾーンが発展 → さらに交通量増加
```

### 人口の上限

- ハードキャップなし
- 渋滞・住宅不足・幸福度低下が自然な天井になる

## 7. 幸福度システム

市民の幸福度は交付金額・人口成長に影響する。

### 幸福度の構成要素

| 要素 | 評価方法 | 影響（幸福度への寄与） |
|------|---------|---------------------|
| 通勤時間 | 平均通勤時間 | 最重要（±30%） |
| 公園・緑地 | 住宅地からの距離 | ±10% |
| 騒音（幹線道路隣接） | 幹線から50m以内の住宅数 | -10%まで |
| 公共交通のアクセス | バス停・駅からの距離 | ±10% |
| 商業施設の充実 | 商業ゾーンの充足度 | ±10% |
| 災害被害 | 直近の冠水・土砂崩れ | 一時的に-20% |

### 幸福度の効果

```
幸福度 >= 80: 交付金+10%（幸福度ボーナス）、人口成長ボーナス
幸福度 50〜80: 通常
幸福度 30〜50: 交付金-20%（幸福度ペナルティ）、人口成長鈍化
幸福度 < 30: 交付金-20%、人口流出開始
```

## 8. 交通渋滞の判定と評価

### 渋滞度（道路区間ごと）

```
渋滞度 = 現在の流量 / 道路容量

渋滞度 < 0.6: 青（スムーズ）
渋滞度 0.6〜0.8: 黄（やや混雑）
渋滞度 0.8〜0.95: 橙（渋滞）
渋滞度 >= 0.95: 赤（深刻な渋滞）
```

### 道路容量（台/時間）

| 道路種別 | 1車線あたりの容量 |
|---------|----------------|
| 生活道路 | 600台/h |
| 県道 | 900台/h |
| 国道 | 1,200台/h |
| バイパス | 1,800台/h |
| 高速道路 | 2,200台/h |

### 平均通勤時間の計算

```
対象: 走行中の全車両（バス・緊急車両・大型トラックを除く）
計算: 各車両の「出発からの経過ゲーム時間」の移動平均（直近 200台）
更新: ゲーム内 1時間ごとに再計算

avgCommuteTime = movingAverage(vehicle.elapsedTime for all active vehicles, N=200)

Vehicle に追加フィールド:
  GameTime departedAt;  // 出発（生成）時刻

表示: HUD左下に「平均通勤時間: XX分」として表示
```

### 街全体の評価指標

HUD上に常時表示:

| 指標 | 内容 |
|------|------|
| 平均通勤時間 | 直近200台の移動平均（HUD左下） |
| 渋滞ポイント数 | 渋滞度0.8以上の区間数 |
| 道路充足率 | 需要に対する道路供給比率 |
| 月次収支 | 黒字/赤字 |
| 現在資金 | 億円単位で表示 |

## 9. バランス調整のガイドライン

### ゲーム進行の目安

| ゲーム年数 | 人口 | 主なプレイヤー行動 |
|-----------|------|-----------------|
| 開始〜5年 | 1.5〜2万人 | 信号調整・小規模迂回路 |
| 5〜15年 | 2〜4万人 | バイパス計画・建設 |
| 15〜30年 | 4〜7万人 | 幹線拡幅・環状道路 |
| 30年以降 | 7万人〜 | 高速道路IC・大規模再開発 |

### 資金難になったときの回避手段

- 低優先度の公共施設を一時閉鎖（維持費削減）
- バス路線を廃止（需要の低い路線から）
- 旧道廃止で維持費削減
- 人口増加・幸福度向上が交付金増加につながる（長期的な解決策）

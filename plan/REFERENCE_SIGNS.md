## 1. 道路標識の5分類

| 分類 | 記号番号帯 | 基本色（地色 / 図柄） | 形状 |
|---|---|---|---|
| 案内標識 | 101 〜 126 | 一般道: 青地・白文字、高速道: 緑地・白文字 | 正方形・長方形（内容により可変） |
| 警戒標識 | 201 〜 215 | 黄色地・黒図柄（黒縁） | 正方形を45°回転させたひし形 |
| 規制標識 | 301 〜 332 | 白地・赤縁・青地など種別による | 円形（通行禁止系は赤縁）・長方形（通行区分系は青） |
| 指示標識 | 401 〜 409 | 青地・白図柄 | 正方形・正三角形（横断歩道等） |
| 補助標識 | 501 〜 514 | 白地・黒文字（始終点は赤矢印も使用） | 長方形（本標識の下に付設） |

### 2.3 おにぎり標識（国道番号 118）のフォーマット

- **形状**: 五角形（逆五角形「おにぎり」形）
- **118-A（一般国道）**: 白地・青文字・青縁、最大2〜3桁の数字
- **118-B（高速自動車国道指定区間）**: 赤地・白文字
- **118-C（都市高速等）**: 黄地・青文字
- 都道府県道は **六角形**（118の2系）で色・形状が路線種別ごとに異なる

## 7. 寸法・色彩の基本ルール

### 7.1 標識板の基本寸法（センチメートル）

| 種別 | 寸法（cm） | 備考 |
|---|---|---|
| 警戒標識 板1辺 | 45（標準）| ひし形の対角線が約64cm相当 |
| 規制標識（円形）直径 | 約24〜50 | 標識番号・設置場所により異なる |
| 指示標識 | 80×80（標準） | |
| 補助標識 | 横幅は本標識に準ずる、縦15〜100 | |

### 7.2 色彩仕様（マンセル値ベース）

| 色名 | 主な用途 | 代表マンセル値 |
|---|---|---|
| 赤 | 禁止・制限系標識の縁・地 | 7.5R 4/14 |
| 青（案内・指示）| 案内標識地・指示標識地 | 2.5PB 3/10 |
| 緑（高速案内） | 高速道路案内標識地 | 7.5GY 4/6 |
| 黄色（警戒） | 警戒標識地 | 2.5Y 8/12 |
| 白 | 文字・図柄・縁（多用途） | N9.5 |
| 黒 | 警戒標識図柄・文字 | N1.5 |
| 橙（赤橙系） | 道路標示・一部規制（停止線等） | 10R 6/14 |

### 7.3 文字の形・大きさ

- 案内標識: **欧文は角ゴシック（Helvetica系）、和文はゴシック体**
- 高速道路設置標識の文字は、通常の2〜3倍サイズで表示
- 一般道路の案内標識: 和文は概ね1.6cm〜10cm（設置高度・設計速度に応じて）
- 補助標識: 和文最小5mm、数字最小7mm

## 9. 区画線（別表4）

区画線は車道面に引かれる線の種別。道路標示の一部を構成する。

### 9.1 主要な区画線の種別と意味

| 種別 | 線種 | 色 | 意味 |
|---|---|---|---|
| 車道中央線 | 実線（黄） | 黄 | 追越しのためのはみ出し禁止（対向車線との境界） |
| 車道中央線 | 実線（白） | 白 | センターライン（2車線道路一般） |
| 車道中央線 | 破線（白） | 白 | はみ出し可能なセンターライン |
| 車線境界線 | 破線（白） | 白 | 同方向複数車線の区分（車線変更可） |
| 車線境界線 | 実線（白） | 白 | 同方向車線区分（進路変更禁止区間） |
| 車道外側線 | 実線（白） | 白 | 車道と路肩の境界 |
| 路側帯 | 実線+破線 | 白 | 歩行者等が通行できる帯域を示す |
| 駐停車禁止路側帯 | 実線+実線（黄） | 黄 | 停車・駐車禁止の路側帯 |
| 停止線 | 太実線（白） | 白 | 交差点・踏切等で車が停止する位置 |
| 横断歩道 | 縞（白） | 白 | 歩行者横断のためのゼブラ |
| 自転車横断帯 | 縞（白、破線風） | 白 | 自転車用横断帯 |
| 導流帯 | 斜線（白） | 白 | 交差点内等の走行方向を誘導する帯 |
| 安全地帯 | 斜線＋縁（白） | 白 | 歩行者保護の島（路面標示） |

### 9.2 導流帯とゼブラゾーンの違い

| 項目 | 導流帯（指示標示209） | ゼブラゾーン（俗称） |
|---|---|---|
| 法令上の名称 | 「安全地帯又は路上障害物に接近した部分」を含む指示標示 | 「導流帯」（車両通行帯が設けられた道路での車線区分） |
| 形状 | 斜め平行白線（ストライプ）＋縁線 | 斜め平行白線（縁線なしの場合もある） |
| 走行可否 | 車両の通行は可（法的には走行可能）だが通常は進入しない | 基本的に走行は可だが接触リスクに注意 |
| 主な設置場所 | 交差点付近の空き空間、分岐・合流部手前 | 広い交差点内、右折待機スペース前方 |

- ゲーム実装観点: どちらも「白斜線が引かれた白縁矩形領域」として描画し、路面の使用不可エリアとして扱うと自然

## 10. ゲーム実装に直結するポイント

### 10.1 一時停止標識（330）の設置ルール

- 形状: **逆三角形**（赤地・白文字「止まれ」）
- 設置位置: 交差点の停止線の直前（見やすい位置）、または歩道に立てる
- 補助標識との組み合わせ: 原則単体。時間・区域限定には補助標識501/502を併用
- 路面標示との関係: 必ず**停止線（規制標示114）**とセットで描画する
- 一方通行道路や信号なし交差点で対向方向に対して設置

### 10.2 徐行標識（329）

- 形状: **逆三角形**（白地・黒枠・黒文字「徐行」）
- 一時停止との違い: 一旦停止は不要、速度を十分落として安全確認だけで良い
- 設置場所: 見通しの悪いT字路・構内道路・踏切の手前など

### 10.3 速度標識（323/324）

- **最高速度（323）**: 赤縁円に速度数値（白地・黒文字）。法定速度は標識なしでも適用（60km/h）
- **最低速度（324）**: 青縁円。高速道路の最低速度（50km/h）に主に使用
- 補助標識502で時間帯限定が可能

### 10.4 おにぎり板（国道番号118）の描画

- 一般国道（118-A）: 五角形・白地・青縁・青文字
- 高速指定区間（118-B）: 五角形・赤地・白文字
- 都市高速（118-C）: 五角形・黄地・青文字
- 都道府県道（118の2系）: 六角形または独自形状・色は路線管理者ごとに異なる
- **ゲームでの実装**: 五角形ポリゴンに番号テキストをレンダリングし、地色を路線種別で切り替え

### 10.5 案内標識の色による道路種別識別

| 標識地色 | 意味するネットワーク |
|---|---|
| 緑地 | 高速自動車国道・指定都市高速 |
| 青地 | 一般国道・都道府県道・市区町村道 |
| 白地（おにぎり） | 国道番号そのもの（経路ではなく路線識別） |

### 10.6 交差点の道路標示セット

交差点を生成する際に描画すべき標準セット:

1. **停止線（114）** — 各進入方向の停止位置（幅15〜45cm 白実線）
2. **横断歩道（115）** — 横断する各辺（縞幅45cm以上、縞間隔50cm程度）
3. **横断歩道予告菱形（115指）** — 停止線から約30m 手前の路面菱形マーク
4. **センターライン（中央線201）** — 交差点手前で終了 or 交差点内中断
5. **進行方向矢印（119）** — 右折専用・直進・左折レーンに対応した矢印
6. **導流帯（209）** — 広い交差点では右折待機ゾーンに設置

### 10.7 標識柱の高さ・取付け基準

- 警戒標識・規制標識・指示標識の柱: **地上高100cm以上**
- 案内標識（高速道路オーバーヘッド型）: 車両が通過できる十分な高さ（通常5.5m以上）
- 補助標識は本標識の下に直接付設

### 10.8 反射材

- 夜間視認性確保のため、全標識に反射材使用または反射塗料塗布が義務
- ゲームでは夜間レンダリング時に自発光・リムライト処理の参考に

### 10.9 路面標示の色ルール（まとめ）

| 色 | 用途 |
|---|---|
| 白 | ほとんどの路面標示（車線・停止線・横断歩道・矢印等） |
| 黄 | センターライン（はみ出し禁止）・路側帯禁止（駐停車禁止路側帯）・一部路面文字 |

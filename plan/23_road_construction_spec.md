# 道路建設・用地撤去

## 着工と通行

道路計画は、生成・編集した候補を「確定して着工」すると費用を支払って建設する。未確定の候補では道路分割・資金消費・撤去を行わない。接続と実費用を仮の道路網で検査し、失敗なら候補を保持する。既存の保存済み計画も一覧から着工できる。資金確認後の着工時に `GameScene::prepareConstructionSite` を呼び、建物と敷地を自動撤去する。計画・個別道路の着工入口を共通処理へ接続する。同じ計画を再度着工する操作は拒否する。

道路断面を曲線に沿って2m間隔で走査し、建物の実モデルの回転付き境界箱と交差判定する。用地は道路構造幅に片側0.5mの余裕を加える。高架では路面下1.5mから上5mまでと橋脚基礎の6m幅を検査し、桁下に十分収まる建物は残す。敷地セルのゾーンを Unzoned にし、建物に属する庭・塀などの LandPatch も削除する。

SimGraph の全構築・部分更新、直接の車線取得とも Planned / UnderConstruction を通行対象から除外する。完成時に Open へ切り替え、交通グラフと道路・地形描画を更新する。計画に所属しない単独道路も60ゲーム秒で完了する。

## 実装の責務

- `RoadPlanDraft` は点列・履歴・候補形状を管理する。`propose()` は接続先の分割を含む仮の道路網を一つだけ作り、確定処理へ渡す。
- `RoadPlanConstruction::commit()` は接続、実費用と資金、既存路線の有効性を検査し、路線・計画の登録と着工がすべて成功した場合だけ道路網を置き換える。失敗時はエラーを返し、道路・路線・計画・ID割当を変更しない。
- `RoadConstructionStart` は個別道路・計画・路線の選択から未着工道路を集める。計画の一部を選んだ場合も計画全体を対象とし、重複IDを除いて見積もる。実行直前に同じ選別と資金確認を行い、資金不足では状態と日時を一切変更しない。成功結果に請求額・対象道路・関連ノードを返す。
- `GameScene_RoadPlan.cpp` は候補の入力とメッセージを扱う。3種類の既存道路パネルは `GameScene::startRoadConstruction()` を使い、各パネルで支払い・状態変更を行わない。
- `GameScene_Construction.cpp` は新規候補・既存道路に共通の成功処理を持ち、用地撤去、1回の支払い、道路描画と交通の更新をまとめる。工期満了による開通もここで扱う。用地・切盛土は従来の計画単位と選択順で準備し、隣接する複数計画を1回の地形計算へまとめない。
- 地上1倍・高架3倍・トンネル6倍の換算延長は `RoadEdge::constructionEquivalentLength()` に集約し、候補の概算・確定時の請求・計画の集計で共用する。料金の係数は従来どおり。工期は昼夜のカレンダーと切り離し、標準速度で換算延長1kmあたり生活道路60秒・幹線120秒・自動車専用道360秒・高速道路720秒、最短5秒とする。70mの生活道路は5秒で開通する。停止・2倍・4倍速は引き続き工期にも適用する。見積りは現実の待ち時間を秒・分で表示する。計画に属さない単独道路の料金は従来どおり実延長を使い、既存道路パネルの資金比較許容差は1e-6億円を保つ。

## 工程

| 地上道路 | 高架道路 | 表示 |
|---|---|---|
| 既設物撤去工 | 既設物撤去工 | 撤去済みの用地、重機、仮設バリケード |
| 土工・路床工 | 下部工（基礎・橋脚） | 露出土と浅い轍 / 基礎、鉄筋、型枠、足場、打設中の柱 |
| 路盤工 | 上部工（桁・床版） | 敷き進める砕石 / 架設していく鋼桁と床版 |
| 舗装工（基層・表層） | 橋面舗装工 | フィニッシャーとローラー、延長に沿った舗装 |
| 区画線工 | 区画線工 | 延長に沿って増える道路標示 |
| 供用開始 | 供用開始 | 通常の道路・交差点描画 |

呼称・写真資料は `artifacts/road_construction/REFERENCES.md`。地上の工程境界は12/36/56/88/100%、高架は10/40/70/90/100%。これらはゲーム用の時間配分であり実工期の見積りではない。

時刻は既存の constructionStart / completionDate から算出し、描画処理で時刻を進めない。停止・ロードで同じ進捗を保つ。描画メッシュは工程内5%刻みで更新し、フレームごとのモデル生成と全世界の撤去判定を避ける。

## 描画

工事用重機4種は実寸の独自OBJ。履帯・ドラム・ホッパー・スクリード・伸縮ブーム・アウトリガーを作り分け、単一マテリアルに局所AOを焼き込む。モデルは事前ロードし近距離で使用する。静的シャドウへも登録する。

土・砕石には実写 diffuse / normal と専用ピクセルシェーダーを使用し、回転したサンプルを合成して反復を抑える。地上の工事用地は描画上の掘削面を下げ、舗装まで土・砕石のメッシュを表示する。地形シミュレーションの標高は変更しない。

橋脚は面取りしたテーパー柱と張り出し梁・基礎で構成し、施工中と完成後で同じ形状を使う。柱の打設、露出配筋、型枠と足場を進捗に応じて表示する。上部工は鋼I桁とコンクリート床版を部分架設する。橋脚位置の植生を避け、高架下全体を更地にはしない。

## 永続化

`global/construction_clearance.json` に撤去したチャンク・セルを記録する。建物と敷地の手続き再生成後に再適用し、道路を後で削除しても撤去した建物は復活させない。スナップショット書き込みと検証に含める。ファイルがない旧セーブは読み込める。破損・欠落フィールド・範囲外座標は読み込みを拒否し、読み込み途中で現在の履歴を置き換えない。

## 検証

`Test/RefactoringTests.cpp` は計画全体への展開、重複課金防止、資金不足での無変更、各パネルの選択に対する同一結果を検証する。`Test/RoadConstructionTests.cpp` で時刻と保存復帰、回転建物と高架の高さ判定、別チャンクの敷地キー、破損履歴、通行制御、橋脚面の向き、全工程と近接描画を確認する。`--capture-construction --seed 42 --new` は隔離した作業ディレクトリで本体の新規都市を使い、自動撤去から開通まで撮影・計測する。プレイヤーのセーブを上書きしない。

撤去費用の独立した内訳、計画中の撤去対象ハイライト、部材搬入車の運行、地下杭の施工アニメーションは含まない。

## サンドボックスと生成曲線

サンドボックスは新規道路と既存計画の着工で資金確認・引落しを省略する。形状・勾配・接続の検査、用地撤去、工事進捗は通常と共通。

道路計画の自動生成は `RoadAlignment` の確定した制御点をそのまま保存する。ドラッグで点列を編集した場合だけ共通の `fit` で曲線を作り直す。以前の計画のプレビューや探索状態を次の道路に流用しない。

# コマンドパレット

`/` キーで左下に開く。入力中はカメラ移動・時間操作・建設のショートカットへキーを渡さない。`Enter` で実行、`Tab` で現在の単語を補完、`↑` / `↓` で最大64件の実行履歴、`Esc` で閉じる。IME変換中の Enter はコマンドを実行しない。

候補には書式と説明を表示する。`<id>` などは実際の数値へ置き換える。例: `/road status set 1446 p` から Tab で `/road status set 1446 planned` を補完する。

| コマンド | 意味・値 |
|---|---|
| `/help` | コマンド一覧と本書の場所 |
| `/time set 13 46` | 13時46分。時は0～23、分は0～59。日付を保持 |
| `/day set 1 4 2` | 1年4月2日。時刻を保持。年は1～9999、月は1～12、日は1～30 |
| `/road inspect 1446` | 道路1446の状態、延長、構造 |
| `/road status set 1446 planned` | 指定区間を計画中・路盤未建設へ変更 |
| `/road status set 1446 construction` | 指定区間を現在時刻からの工事中へ変更 |
| `/road status set 1446 open` | 指定区間の路盤を完成させて供用 |
| `/road status set 1446 closed` | 指定区間を完成済みの通行止めへ変更 |
| `/camera goto 33000 32000` | X、Z座標へ俯瞰視点で移動。0～65535 m |
| `/camera zoom 6000` | 俯瞰距離。5～60000 m |
| `/money set 25.5` | 資金を25.5億円へ設定。0～10億億円 |
| `/speed set 0` | 時間停止。1、2、4で各時間速度 |
| `/fps on` / `/fps off` | 左下のFPSグラフを表示・非表示 |

構文・数値範囲・IDを検査してから状態を変更する。不正な入力は理由を表示し、ゲーム状態を変更しない。

道路状態の変更は指定したエッジだけに作用する。計画に所属する区間は計画から外し、残りの工事が後日その区間を上書きしないようにする。車線、路盤部品、接続、地形・描画キャッシュ、交通経路を同期する。道路を `planned` に戻しても、それ以前の建設で変形した地形や撤去した建物は復元しない。

時刻・日付の変更はデバッグ用の時刻ジャンプ。標準速度の一日24分は変更しない。過去へ戻しても、建設・交通・経済の履歴は巻き戻さない。カレンダーはゲーム共通の1か月30日。

実装: `src/debug/GameCommands.*`（解析・補完）、`CommandExecution.*`（状態変更）、`src/ui/CommandPalette.*`（表示・入力）、`GameScene_Commands.cpp`（描画・交通への反映）。

# 現行実装の概要

2026-09-17時点。Pavecityは、Siv3D 0.6.16 / Windows x64で日本の都市・田園と交通網を生成し、道路計画、建設、街歩き、自由運転を行うゲーム。実景に近い寸法・町割・素材感を目指す。以下は実装済み範囲と制約であり、将来構想を含む旧設計書とは区別する。

## 遊び始める

1. `App/City.exe` を `App/` を作業ディレクトリとして起動する。シードと生成要素のチェックボックスを選んで街を生成する。保存済みの街は一覧からロード・削除できる。
2. `M` で地図、ホイールで拡大、右クリックの「ここへジャンプ」で街角へ移動する。
3. `F` で目線1.5mの徒歩視点。WASD、Shiftで走行、Ctrlで高速移動。もう一度Fで俯瞰へ戻る。
4. `R` で道路を選び、始点・終点をクリック。「経路生成」で候補を作り、点や線をドラッグして調整。「確定して着工」またはEnterで建設する。開通までの実時間を表示し、短い生活道路なら標準速度で5秒で開通する。
5. `Z` で用途を選び、道路の隣を住宅地や商業地に指定。条件に合う空地は約10〜34秒で開発し、需要と待機理由をパネルで確認できる。
6. `C` で道路へ乗車。Wでアクセル、Sでブレーキ・後退、A/Dでハンドル、Spaceで強ブレーキ。Cで降車、Fで俯瞰へ戻る。
7. Spaceで時間の停止・再開（運転中はP）。Escでツールを解除し、閲覧状態でもう一度Escを押すとポーズメニュー。

詳細な操作・入力の優先順位は [06](06_ui_spec.md)。新規生成された住宅に応じて初期人口を設定する。初期資金は30億円で、既設道路の維持費と人口に応じた交付金を月ごとに精算する。[04](04_gameplay_detail_spec.md)

## 生成・鉄道操作の追加

平野はマップ面積の最大50%、都市は最大4個。山村、沿道型の町、曲がる畦道と行き止まり接続、遠回りする村間の新道を生成する。英語接尾辞は City / Towm / Vill.。電車・駅をクリックして情報表示と列車追跡、Uで地下断面へ切り替えられる。生成項目と保存復帰を共通化した。詳細は [33](33_generation_and_underground.md)。

## 生成とデータの流れ

中心市街地の小街区・狭い敷地と、市の郊外に生成するニュータウンを追加。ニュータウンは戸建て地区・集合住宅地区・生活中心・植樹した緑道を分け、歩行者専用路を実際の徒歩経路へ接続する。[仕様24](24_japanese_urban_morphology.md)・[写真資料](research/2026-09_newtown_photo_study.md)

生成調整値は `App/assets/generation/` のJSONを一度読み込む。建物前で発着する通常交通は最大12,000台。全OBJと手続き生成形状に距離別の簡略描画を用意する。詳細は [生成設定・LOD・大量交通](28_generation_assets_lod_traffic.md)。

`MapGenerator` → 集水・河川と地形 → 集落類型・町割 → 道路接続・城下町外縁と設計縦断 → 水域横断の修正 → 切土・盛土 → 狭小街区の統合 → 鉄道 → 地区・地名 → 接続する農道と田舎の家 → 敷地・建物 → 農道間の不整形ほ場。

- 64×64チャンク、1チャンク1024m。基礎高さ場は16m格子。
- 城下町、宿場、門前、港、駅周辺、農村などの成り立ちを、道路方向・街区寸法・土地利用へ反映する。[24](24_japanese_urban_morphology.md)
- 城下町の外側は深さの違う生活道路と街道沿いの家並みへ移行する。田畑は外の道路につながる耕作道と、畦・進入口・用排水路を持つ。[24](24_japanese_urban_morphology.md)
- 大きい街区は路地と沿道建物で埋め、建築不能な狭小街区は接続を保って統合する。
- 道路は生活道路・サブ幹線・幹線・一方通行を使い分ける。歩道と標示も断面・接続相手に応じて決める。
- 道路の横断面は中心線高を共有。乾いた小さな切盛土は地形を造成し、水域・高い谷越えは橋梁、地中区間はトンネルとする。
- 鉄道は構造費・地形・勾配・道路離隔を評価して線形を選ぶ。川は集水格子を水源推定に使い、連続地形の最急降下方向を追跡する。川と湖の水面材質を共有し、川の幅・水位・河床・植生除外を同じ流路データから得る。[26](26_landscape_transport_spec.md)

## 更新と描画の責務

- メインスレッド: 入力の優先順位、時計、建設・経済、描画、GPU転送。道路計画の入力は `GameScene_RoadPlan`、確定の検査・登録は `RoadPlanConstruction` に分ける。
- プレイ中の開発: `ZoneDevelopment` が塗った空き区画の確認と建物・敷地生成を担当する。`GameScene_Zoning` はパネル、入力モード、人口・需要の反映を接続する。
- 集落の開発: `SettlementDevelopment` が用途地域、建物、敷地、接道方向、生成制約の検証を担当する。シーンは世界・道路・鉄道・地区・シードを渡し、検証結果を受け取る。
- 道路計画: 候補から一つの仮の道路網を作り、接続・資金・路線登録・着工の成功後に反映する。失敗時は道路分割やID割当も残さない。既存道路の着工は `RoadConstructionStart` が計画単位の見積もりと資金確認を行い、成功後の撤去・支払い・交通と描画の更新は `GameScene_Construction` に集約する。
- 道路網: ノード・エッジ・路線・計画の所有元は `RoadNetwork` のまま、接続形状、車線接続、標識、路線、計画の実装を分割する。
- `SimThread`: 経路探索。`SimGraph` の読み取り専用スナップショットで共有データ競合を避ける。
- `WorldRenderer`: 表示対象の選別を本体、地形の切り抜きを `_Terrain`、非同期処理とGPU転送を `_Streaming`、敷地・植生・建物を `_Buildings` に分ける。キャッシュの所有元は一つに保ち、地形と敷地の境界計算には `TerrainSurfaceGeometry` を共用する。建物の店先はモデル・種類ごとの共有メッシュ。
- `RoadRenderer`: 道路・交差点のメッシュ、標示、設備をIDでキャッシュ。断面の近景/遠景を一度ずつ生成し、遠景の材質別結合にも同じメッシュデータを使う。
- `WorldMapView`: 道路・川・境界・ラベルを描いた画像を、表示中心・縮尺・画面サイズ・データ更新が変わるまで再利用。現在位置・住所・メニューは別に更新する。縮小時も生活道路を消さない。
- `KeyboardActions`: Windowsキーイベントの番号を追い、フレーム間で完結する短い押下を一度だけ扱う。IME文字入力は既存のSiv3D入力に任せる。

## 検証と再現

Releaseの `City.sln` は本体と常設Testをビルドする。Testは自動終了し、`Test/App/TestResults/results.json` に結果、`Test/App/Screenshot/` にGPU読み戻しを保存する。

| 起動オプション | 用途 |
|---|---|
| `--playtest-commands <JSONパス> --seed 42 --new` | 明示指定したローカルファイルから運転・視点・計画操作を受け、通常更新と描画で検証。通信なし。idを増やして命令し、playtest_state.jsonで状態・音声出力を読む |
| `--playtest --seed 42 --new` | 通常プレイ。入力、モード、資金、カメラ座標、フレーム時間をローカル記録。F12で撮影（F10も対応） |
| `--benchmark-streaming --seed 42 --new` | ウォームアップ後の固定720フレーム飛行。自動終了 |
| `--capture-city --seed 42 --new` | 城下町外縁と農道の徒歩視点を含む35視点をローカル保存 |
| `--benchmark-navigation --seed 42 --new` | 徒歩・俯瞰を切り替える6段階の診断。自動終了 |
| `--capture-road-ux --seed 42 --new` | 道路計画の生成・編集・Undo・Redo・資金確認・着工を描画検証 |
| `--capture-rail-signs --seed 42 --new` | 2両・4両編成、市町村界、道路の通称名を実都市で検証 |
| `--capture-transport --seed 42 --new` | 街、川、橋、坑口、地図、徒歩を14視点で検証 |
| `--audit-road-integrity --seed 7 --new` | 生成ログと道路スナップショットを保存して終了 |

`--new` は引数末尾に置く。計測は本体を一つだけ起動し、同じシード・経路・解像度・時刻で比較する。CPU時間とフレーム間隔を混同しない。通常プレイで起きた不具合の再現値と修正結果は [プレイテスト記録](../artifacts/playtest_refinement/REVIEW.md)、未解決事項は [ISSUE.md](../ISSUE.md)。

### 2026-09-15 集落の生活圏

`SettlementPlacement` が周囲の耕地と地形上の往来費用から中心町・周辺農村を配置する。近郊農村の一律都市化を廃止し、中心との関係を村の間隔と道路接続順・方向に反映する。`settlement_audit.json` に位置・規模・生活圏を記録。詳細と調査資料は24章§8。

## 2026-09-15 周辺農村・地域地形・道路費用・俯瞰地名

都市へ往来しやすい農地の村間隔を1.4–3.4kmへ強化。シードで向きを変える海岸・大きな湾・2本の蛇行する山地・横谷と峠を共通の地形関数で生成する。道路は地上1／掘割8／高架64＋高さ[m]×16＋指数罰則／トンネル128＋連続延長の指数罰則の費用を平面探索と縦断計画で共有し、すでに成立する高価な回廊も安い迂回候補と比較する。俯瞰には街の上の地名を追加し、徒歩と運転は従来の固定ヘッダを維持する。

仕様は03・06・24・27章。検証と有限探索の制約は `artifacts/regional_landscape/REVIEW.md` を参照。

### 2026-09-16 都市外縁の住宅と農地

- 住宅街を都市の外に1〜3段接続し、外側ほど通り・住宅占有率を減らす。郊外は戸建てと低層住宅を中心にする。
- 田畑は町割に沿う道路から伸ばした農道と方向を共有し、地形に応じた不整形区画を作る。農道は普通道路で、全ての田畑の端まで500m以内に田舎の家を置く。
- 詳細は [都市形態](24_japanese_urban_morphology.md)、検証は [今回の記録](../artifacts/regional_landscape/REVIEW.md)。

### 2026-09-16 平野・海岸・中央の開発余地

平野の複数スケールの起伏と海岸の2次元変形を追加した。山地は内陸・側縁を基本とし、中央の山・大湾・湖はシードごとの変化として残す。中央に実際の適地を残す地形生成で対応し、街の位置・道路・建物の制約は維持する。新地形で再現した鉄道候補の不成立による生成停止も修正し、接続できた駅・路線を残して街を生成する。現行地形の正本は03章、鉄道の不成立時の仕様は10章、検証は `artifacts/terrain_composition/REVIEW.md`。

### 2026-09-17 景観・選択・描画

農道の道路グラフ統合、不整形農地、集落中心からの密度減衰、家まで500mの保証を追加。トンネル連続長・高架高さの指数費用、車体10色、敷地と電車の黄色い選択線、F3のFPSグラフを実装。地図画像の更新順序と敷地メッシュの表裏を修正し、木と道路は詳細表示より遠い範囲で準備する。

## 俯瞰・生成・デバッグの追加仕様

俯瞰は最大60km、ポインタの地名・道路名・国道マークと、市町村名のローマ字を表示する。全画面地図と周辺地図はトンネル部分を破線にする。町村は採用率1/4、全集落中心は端から1km以上。農道は完成状態で生成し、近傍道路への接続を優先する。自然植生は森林限界・高山植生・雪と500mの境界遷移を持つ。経路比較費は地上1・掘割8・高架64＋高さ罰則・トンネル128＋長さ罰則。

`/` で [コマンドパレット](28_commands.md) を開く。通常経路生成とプレビュー・建設は同じ線形を維持し、サンドボックスでは資金による着工制限を省く。検証項目は [全項目チェックリスト](../artifacts/comprehensive_20260917/CHECKLIST.md)。

### 2026-09-17 表示・細道交差点の調整

- ポインタ位置の住所・道路名は左下の小さな背景なし表示。地図と俯瞰の地名も背景なしで読みを併記。
- 地域LODの地形材質・UVを詳細地形と統一し、ズーム境界での明るさの段差を解消。
- 畦道・2車線以下の生活道路だけの交差点は自動信号の対象外。

## 道路・鉄道の共通路盤（2026-09-17）

線路を共通道路網の軌道車線へ統合。バラスト・スラブ路盤、上下別の複線、車道と軌道の併設断面を追加した。自動生成は複線になり、半径300m・勾配1.8%の鉄道制約を完成形で検査する。車と列車の通行資格、列車の方向別予約、共通断面の保存・編集・描画に対応。詳細は [鉄道仕様](10_railway_spec.md)、検証は [共通路盤の記録](../artifacts/shared_transport_20260917/REVIEW.md)。

## 現代都市の7類型（2026-09-17）

東京・大阪、京都、富山、福岡、札幌、長崎、仙台を比較し、地域中心都市へ成立起源とは別の構造型を追加した。拠点・街区・幹線階層・建物密度と高さ構成・複数駅・公園を共通の計画から生成する。値は `assets/generation/urbanStructures.json`。地形条件とシードで自動選択し、町村とニュータウンは従来の生成を保つ。仕様は24章§10、[調査](research/2026-09_japanese_city_structures.md)、[検証](../artifacts/urban_types_20260917/REVIEW.md)を参照。

## 都市の拠点施設（2026-09-17）

高層オフィス2種、市役所、郊外モール、病院、学校を専用建物として追加。道路・地形・隣家・公園を避けて住宅より先に配置する。地域中心都市の主駅は橋上コンコースを持つターミナル駅。東京型・福岡型には地上入口と徒歩接続を持つ地下駅・スラブ複線・編集可能な既定ダイヤを生成する。新建物は全3段階LOD、既存の選択・発着・保存へ接続。[仕様](32_urban_facilities.md)、[検証](../artifacts/urban_facilities_20260917/REVIEW.md)。

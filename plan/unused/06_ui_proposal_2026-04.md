## 2. モード一覧

プレイヤーが操作するモードを以下の5種とする。モードはツールバー左端のボタンで切替。

### 現行実装（2026-04）

実装済みの編集モードは以下。仕様上の「施設建設モード」はまだ統合されておらず、
鉄道とバス路線は独立モードになっている。

| 実装ID | モード名 | キー | 備考 |
|---|---|---|---|
| 1 | 閲覧モード | `Esc` | `EditMode::None` |
| 2 | 道路計画モード | `R` | 始点/経由地/終点から仮計画を生成し、保存・着工・一覧管理を行う |
| 3 | ゾーン塗りモード | `Z` | オーバーレイ自動表示 |
| 4 | 地形編集モード | `G` | `Ctrl+Wheel` でブラシ半径変更 |
| 5 | 線路敷設モード | `X` | 駅ノード追加と線路接続 |
| 6 | バス路線モード | `B` | 停留所列ベースの簡易路線編集 |
| 7 | サンドボックス編集 | `V` | sandbox 起動時のみ、ノード/制御点直接編集 |
| 8 | 道路敷設デバッグ | `Ctrl+R` | sandbox 起動時のみ、旧即時敷設フロー |

| ID | モード名 | キー | 説明 |
|----|---------|------|------|
| 1 | 閲覧モード | `Esc` | デフォルト。クリックで情報表示のみ |
| 2 | 道路計画モード | `R` | 道路ルートを設計・計画一覧管理 |
| 3 | ゾーニングモード | `Z` | ゾーンを塗る・市街化区域を変更 |

| 5 | 地形編集モード | `T` | 掘削・盛土・造成 |

### Undo（Ctrl+Z）

対象操作（Undo 可能）:
  ・ゾーン塗り
  ・道路計画の作成・削除（未着工のもののみ）
  ・施設の配置（建設開始前のもの）
  ・地形編集（掘削・盛土・平坦化・埋立）

対象外操作（Undo 不可）:
  ・着工（資金消費後の工事開始）
  ・完成・開通済みの道路の変更
  ・経済・人口の変化
  ・時間の経過

Undo 履歴: 最大 20件。それ以前の操作は取り消し不可。
着工を取り消したい場合は「中断（違約金 20%）」を使用すること。

## 4. 閲覧モード

- 何もない場所をクリック → 情報なし
- 道路をクリック → 右パネルに道路情報（種別・混雑度・所属計画・維持費）
- 建物をクリック → 右パネルに建物情報（種別・成長段階・築年数・ゾーン）
- 車両をクリック → 右パネルに車両情報（種別・現在速度・目的地・経路表示）

## 5. 道路計画モード

### 道路計画パネル（2026-09-12 実装）

`R` で右パネルを表示する。操作は「道路を選ぶ → クリックして延長 → 見積りを確認して保存」の順。

- 生活道路（対面2車線・30km/h）、サブ幹線（対面2車線・40km/h）、幹線（4車線・50km/h）、一方通行（1車線・30km/h）をカードから選ぶ。断面・車線・幅員も同時に更新。一方通行は点を置く順に進行する。
- 初期は直線。地形に沿う自動経路へ切り替え可能。自動経路の再計算は点の確定・編集時だけ行う。
- 1クリック目で始点、以降のクリックで区間を追加。3点目は経由点付きの延長になる。「終点を調整」は次のクリックで末尾の点だけを移動する。
- 水色の線で確定済みの計画幅員、白い点線で次の区間、緑色で道路への接続候補を表示。自動経路モードでのカーソル線は直線距離のガイドであり、実際の経路はクリック後に計算する。
- 既存の端点・交差点・道路途中へ12m以内でスナップ。異なる高さの道路は候補から除く。道路途中への接続は保存時にその道路を分割する。接続先の元の路線・計画は維持する。
- `Shift` で45度刻みの角度に揃える。`Alt` 押下中はスナップを一時解除。「道路に接続」ボタンで常時ON/OFFを切り替える。
- 右クリック、`Backspace`、`Ctrl+Z`で編集中の操作を戻す。`Ctrl+Y` または `Ctrl+Shift+Z`でやり直す。パネルにもボタンを設置。履歴は現在の仮計画内、最大128操作。保存済みの計画には適用しない。
- 2m未満の区間は受け付けず、理由を表示する。10m程度の短い道路は経路探索セルのサイズによらず生成できる。
- 延長・概算費用・工期を保存前から表示。`Enter` または「計画を保存」で未着工の計画一覧へ追加する。保存時は資金を消費せず、一覧の「着工」で費用を支払う。
- 入力欄の編集中はショートカットを抑止する。`Esc`は仮計画の破棄を優先し、空の状態でもう一度押すとツールを終了する。右パネルを閉じた状態では地面への配置を受け付けない。
- 仮計画は独立した道路網を使う。破棄しても既存道路は変わらず、保存時の接続が失敗した場合も道路分割を含めて一切反映しない。

表示の共有部品は `RoadPlanToolbar`、点列・Undo/Redo・プレビューは `RoadPlanDraft`、近傍の接続候補は `RoadPlanSnapIndex` が担当する。`Test/RoadPlanUxTests.cpp` で表示・短区間・接続・失敗時の非破壊性を検証する。実画面は `--capture-road-ux --seed 42 --new` で開始・延長・Undo・Redo・保存を撮影し、自動終了する。

## 6. ゾーニングモード

### ツールバー（ゾーニングモード時）

```
ゾーン: [低層住居▼] | ツール: [ブラシ▼] | サイズ: [●●●__]
[市街化区域変更モード]
```

### ゾーン塗りツール

| ツール | 操作 |
|-------|------|
| ブラシ | 左クリックドラッグで円形範囲を塗る。サイズはスライダーで調整 |
| 矩形 | 左クリックドラッグで長方形を塗る |
| バケツ | クリックで連続する同一ゾーンを一括変更 |
| 消去 | 左クリックドラッグで未指定に戻す |

- 右クリック → 塗りをキャンセル（未確定ならUndo）
- ゾーン変更に審査期間・費用がかかる場合、塗った後に確認ダイアログが出る

### 市街化区域変更モード

- ツールバーの [市街化区域変更モード] で切替
- 境界線を描いて市街化区域を拡大・縮小
- 拡大後に確認ダイアログ（費用・手続き期間を表示）

## 7. 施設建設モード

### ツールバー（施設建設モード時）

```
カテゴリ: [交通▼] | [鉄道▼] | [公共施設▼] | [緑地▼]
```

| カテゴリ | 建設可能物 |
|---------|-----------|
| 交通 | バス停・信号機・駐車場・駅 |
| 鉄道 | 路線計画・ダイヤ編集・駅・信号所・車両基地・車両購入 |
| 公共施設 | 学校・病院・役所・消防署・警察署 |
| 緑地 | 公園・街路樹 |

### 建設フロー

```
① カテゴリ・種別を選択
② マップ上でプレビューが表示される（半透明）
   ・配置可能 → 緑色プレビュー
   ・配置不可（建物重複・ゾーン不一致） → 赤色プレビュー
③ 左クリックで配置確定（即時 or 建設期間あり）
```

### バス路線の設定

```
① [バス路線] を選択
② バス停を順にクリックして経路を作成
③ 右クリック or Enterで路線確定
   ・路線名が自動生成される（例:「本町〜駅前線」）
   ・運行費・本数を設定するダイアログが出る
④ [開設] で路線開始（翌ゲーム月から運行開始）
```

### 路線計画フロー

```
① [鉄道] → [路線計画] を選択
② 軌間（狭軌 / 標準軌 / 三線軌条）・電化の有無を選択
③ マップ上でベジェ曲線でルートを描画（道路計画モードと同様）
④ 駅・信号所・踏切の位置を指定
   ・踏切: 道路との交差点を自動検出 → 候補を表示
⑤ [計画確定] → 概算費用・工期を表示
⑥ [着工] で工事開始
```

### ダイヤ編集フロー

```
① [鉄道] → [ダイヤ編集] を選択
② 路線を選択 → スケジュール一覧を表示
③ [新規ダイヤ追加]
   ・使用編成を選択
   ・各駅の着発時刻をスプレッドシート形式で入力
   ・ホームを選択（複数ホームがある駅のみ）
④ [保存] → 翌ゲーム日から運行開始
```

### 車両購入フロー

```
① [鉄道] → [車両購入] を選択
② 車両スペックの一覧から編成を選択
③ 配備する車両基地を選択
④ [購入] → 資金を消費して基地に配備
```

## 11. 一人称視点モード

- `F` キーで切替（閲覧モード時のみ）
- カーソルが道路上にあるときにカメラが道路面に降りる
- `W/S`: 前後移動（歩行速度 or 走行速度）
- `マウス`: 視点方向
- `E`: 最寄りの車両に乗り込む（その車両に追従）
- `F` or `Esc`: 元の俯瞰視点に戻る

## 2026-09-12 HUDと敷地選択

- 左上の街情報と右上の街の動き・地図は、右端の `− / ＋` でそれぞれ折りたたむ。折りたたみ時は高さ32pxの見出しのみを残す。地図は通知の下に配置し、重ならない。
- HUD上のクリックやホイール操作を道路建設・地形編集・背後の選択へ流さない。
- 畑・水田・住宅の庭・砂利や舗装の敷地は通常モードでクリック選択できる。地形に沿ったアウトラインと種別・面積・位置の情報パネルを表示する。建物本体のクリックは従来の建物選択を優先する。
- 敷地選択は描画と同じ道路切り抜き済みメッシュを使い、凹区画の外側や道路部分には反応しない。

## 2026-09-13 全画面マップ

- `M` またはミニマップのクリックで開く。画面全体を覆い、道路・鉄道をベクター表示する。地形・地名・駅名・現在位置・縮尺を表示する。
- ホイールでカーソル位置を基準にズーム、左ドラッグでパン。右上の `＋ / −` でもズームできる。
- 地図上の右クリックから「ここへジャンプ」で地上の該当座標へ移動し、地図を閉じる。車両追跡は解除する。
- `Esc`・`M`・閉じるボタンで戻る。閉じたフレームも入力を消費し、背後の建設・カメラ移動・ポーズメニューへ流さない。
- 道路データ変更時にベクターキャッシュを無効化し、次に開くときに再構築する。地名を重ねず、小縮尺では生活道路を省略する。
- Testの単体画面と操作テストを先に実行し、その後、本体の全画面描画とジャンプ処理を確認した。

# プロシージャル生成仕様書

## 概要

ゲーム開始時にシード値と地形タイプからマップを生成する。
生成物は「既成市街地（旧道＋集落）をもつ平成初期の日本の小さな町」。

---

## 1. 生成パラメータ（開始画面）

| パラメータ | 入力方式 | 説明 |
|-----------|---------|------|
| シード値 | 整数入力 or ランダムボタン | 乱数の種、同じシードなら同じマップ |
| 地形タイプ | 4択ボタン | 下記参照 |

---

## 2. 地形タイプ

### タイプA: 山間盆地（さんかんぼんち）
```
・四方を山に囲まれた盆地
・中央に川が流れ、川沿いに平野が広がる
・旧街道は川に沿って縦断する
・バイパス候補: 山の切り通し or 盆地外周の迂回路
```
```
[山] [山] [山] [山]
[山] [平] [平] [山]
[山] [平] [川] [山]  ← 旧道は川沿いを縦断
[山] [平] [平] [山]
[山] [山] [山] [山]
```

### タイプB: 沿岸平野（えんがんへいや）
```
・片側が海、反対側が山地
・海岸線沿いに旧街道、港町が核になっている
・漁港・観光地の要素あり
・バイパス候補: 山際の新道 or 海岸埋立
```
```
〜〜〜〜〜〜〜〜〜〜  ← 海
[港] [平] [平] [平]
[平] [平] [平] [丘]  ← 旧道は海岸線に沿う
[丘] [丘] [山] [山]
```

### タイプC: 河川扇状地（かせんせんじょうち）
```
・山から流れ出る複数の川が合流する扇状地
・川の分岐・合流が多く、橋が重要インフラになる
・水害・冠水イベントが起きやすい
・バイパス候補: 川の上流側の高台ルート
```
```
    [山]
   /    \
[川]   [川]   ← 複数の川筋
  \    /
  [合流] [平野]
```

### タイプD: 丘陵台地（きゅうりょうだいち）
```
・緩やかな丘が連続する地形
・丘の上に集落、谷に田んぼが広がる
・旧道は丘の稜線に沿う（昔からの道）
・バイパス候補: 谷を貫く新道（トンネル or 高架）
```
```
[丘] [谷] [丘] [谷]
[集] [田] [集] [田]  ← 集落は丘の上
[丘] [谷] [丘] [谷]
```

## 3. 地形生成アルゴリズム

### Step 1: 高さマップ生成

```
1. Perlinノイズ（多重オクターブ）で基本高さマップを生成
   - オクターブ数: 6
   - 周波数: 地形タイプにより調整
   - 振幅減衰: 0.5

2. 地形タイプ別マスクを乗算
   - 山間盆地: 中央を凹ませるラジアルグラデーション
   - 沿岸平野: 片側を低く傾けるランプ関数
   - 河川扇状地: 中央から広がる扇型の傾斜
   - 丘陵台地: 中周波ノイズを強調

3. 高さ値を離散化
   - h < 0.1  → 水域（海・湖）
   - h < 0.2  → 低地（氾濫原・河川敷）
   - h < 0.5  → 平野
   - h < 0.7  → 丘陵
   - h >= 0.7 → 山地
```

### Step 2: 河川生成

```
1. 山地の高点から水を流す（流水シミュレーション）
   - 各セルから最も低い隣接セルへ流れる
   - 流量が閾値を超えたセルを河川としてマーク

2. 河川の浸食処理
   - 河川セルの高さをわずかに下げる
   - 河川沿いに低地（氾濫原）を形成

3. 河川幅
   - 流量に応じて1〜4セル幅
```

### Step 3: 地表種別の決定

| 高さ | 勾配 | 水域 | → 地表種別 |
|------|------|------|-----------|
| 低地 | - | あり | 水域（河川・湖） |
| 低地 | 緩 | なし | 水田・湿地 |
| 平野 | 緩 | なし | 農地・草地 |
| 平野〜丘 | 緩 | なし | 宅地適地 |
| 丘〜山 | 急 | なし | 林地・山林 |
| 山 | 急 | なし | 岩地 |

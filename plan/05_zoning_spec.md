### 住宅充足率

```cpp
housingCapacity = Σ(building.capacity for all residential buildings)
housingDemand   = population
housingRatio    = housingCapacity / housingDemand
// housingRatio > 1.0 → 余裕あり（成長を後押し）
// housingRatio < 1.0 → 不足（成長を抑制）
```

## 2. ゾーン種別（7種）

都市計画法を以下の7種に簡略化する。

| ID | ゾーン名 | 表示色 | モデル |
|----|---------|--------|--------|
| 0 | 未指定 | 灰 | 既存建物は残る・新規開発不可 |
| 1 | 市街化調整区域 | 薄緑 | 農地・公園のみ可 |
| 2 | 低層住居専用 | 黄 | 戸建て・低層マンションのみ |
| 3 | 住居地域 | 橙 | 住宅系全般＋小規模店舗 |
| 4 | 商業地域 | 赤 | 店舗・オフィス・マンション全般 |
| 5 | 工業地域 | 紫 | 工場・倉庫のみ |
| 6 | 農業地域 | 緑 | 農地のみ |

> 公園・公共施設・駐車場はゾーンに関わらずプレイヤーが任意に建設できる（ゾーン外建設扱い）。

## 4. 建物の成長段階

各ゾーンの建物は需要・経過年数に応じて成長・老朽化する。

### 低層住居専用

```
[空地] → [戸建て・昭和] → [戸建て・平成] → [戸建て・令和]
                                              ↘ [老朽化・空き家]
[空地] → [低層アパート] → [低層マンション]
```

### 住居地域

```
[空地] → [戸建て] or [低層アパート]
       → [中層マンション]（需要が高い場合）
住居地域では中層マンションまでが上限
```

### 商業地域

```
[空地] → [小規模店舗] → [大型店舗・SC]
[空地] → [中層マンション] → [高層マンション]
[空地] → [小規模オフィス] → [オフィスビル]
需要の高い種別が優先的に生成される
```

### 工業地域

```
[空地] → [中小工場] → [大型工場・物流センター]
```

### 農業地域

```
[農地] → 変化しない（人の手で維持される）
農地を放棄（ゾーン変更せず道路アクセスも整備しない）→ 荒地に変化
```

## 5. 建物の自動生成ロジック

```
毎ゲーム月、各セルを評価:

  発展スコア =
      道路アクセス係数  // 最寄り道路の種別・距離
    × 需要係数         // 住宅・商業・工業の需要量
    × 地価係数         // 周辺の発展度合い

  スコア > 生成閾値 かつ 空地:
    → ゾーン適合建物を生成（成長段階0）

  スコア > 成長閾値 かつ 生成済み建物:
    → 成長段階を1つ上げる（建て替えに数ゲーム月かかる）

  スコア < 衰退閾値:
    → 老朽化進行（一定年数後に空き家・廃業）
```

## 6. 市街化区域・調整区域

```
市街化区域   … ゾーン（低層住居〜工業）を指定して開発可能
市街化調整区域 … 農業地域・公園のみ。住宅・商業・工業は不可

初期状態: 旧市街地周辺が市街化区域として設定済み
拡大: 市街化区域の境界をプレイヤーが拡張できる
      費用: 拡大面積 × 0.1億円/ha、手続き期間: 3ゲーム月
```

## 7. ゾーン変更のコスト・期間

| 変更内容 | 費用 | 審査期間 |
|---------|------|---------|
| 未指定 → 任意ゾーン | 0.05億円/ha | 1ゲーム月 |
| 住居系 → 商業 | 0.3億円/ha | 2ゲーム月 |
| 住居系・商業 → 工業 | 0.5億円/ha | 3ゲーム月 |
| 工業 → 住居系 | 1.0億円/ha | 6ゲーム月（土壌調査） |
| 農業地域 → 住居系 | 0.8億円/ha | 6ゲーム月（農地転用） |
| 市街化調整区域の解除 | 市街化区域拡大手続きで対応 | — |

## 8. UI・表示

### ゾーンオーバーレイ

Tabキーで3D画面上に半透明カラーをオーバーレイ表示。

表示モード切替:
- **ゾーン種別** （デフォルト）
- **需要ヒートマップ** （赤=需要高・青=低）
- **地価マップ**

### ゾーン塗りツール

| ツール | 操作 |
|-------|------|
| ブラシ | 円形範囲を塗る（サイズ可変） |
| 矩形 | ドラッグで長方形塗り |
| バケツ | 連続する同一ゾーンを一括変更 |
| 消去 | 未指定に戻す |

セルサイズ: **16m × 16m**（チャンク1024m → 64×64セル）

### セル情報パネル

クリックで右パネルに表示:
```

│ 次の成長まで: 4年      │
│                        │
│ [ゾーン変更] [撤去]    │
└────────────────────────┘
```

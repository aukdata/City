# 実装

渡された計画を実装するときに使う。[AGENTS.md](../AGENTS.md) を正本とし、コードの規約は [CODING_STYLE.md](../CODING_STYLE.md)。

- 対象コードと呼出元を調べ、依頼範囲内で実装・必要な修正・関連検証まで完了する。局所的な実装判断は既存パターンに合わせる。
- 計画と実コードが食い違う場合は実態を確認する。要求や公開仕様を変える判断が必要なら、その判断点と候補を報告する。
- 保存処理・キャッシュ無効化・UI・非同期処理への影響は、変更が関係する箇所だけ追う。
- ビルド時は [build.md](build.md)、Test の編集・実行時は [Test/AGENTS.md](../Test/AGENTS.md) を参照する。
- 報告は変更内容、検証結果、残る問題を日本語で簡潔に。計画からの重要な変更があれば理由を添える。

# コードレビュー

[AGENTS.md](../AGENTS.md) と [CODING_STYLE.md](../CODING_STYLE.md) を基準にする。対象は依頼範囲に含まれる全モジュールとし、鉄道・コメント・仕様を一律に除外しない。

- 差分と呼出元を確認し、既存変更・今回変更・未解決の問題を区別する。
- 状態の所有者、非同期処理の寿命、入力の取得元、保存の失敗時、キャッシュの無効化を追う。
- 重複処理は入力条件と返す結果まで比較する。距離検索と接続コストのように意味の違う方針は残す。
- 可読性はファイル長だけでなく、責務境界・名前・日本語コメント・仕様への入口で評価する。
- バグと性能の指摘には再現条件・ID・座標・測定値を添える。未検証の可能性を実際の不具合と断定しない。
- 検証済み範囲と残る制約を明記し、未解決の不具合は [ISSUE.md](../ISSUE.md) で扱う。

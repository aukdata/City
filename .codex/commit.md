# コミット

今回の変更をコミットするときに使う。共通ルールは [AGENTS.md](../AGENTS.md)。

- 作業ツリーとステージ済み差分を確認し、今回の変更だけを意図ごとに分ける。対象パス・必要な差分だけを追加し、`git add .` / `git add -A` は使わない。
- メッセージは日本語で簡潔に。AI の署名・Co-Authored-By は追加しない。
- push は明示的に依頼された場合のみ。履歴の書き換え、amend、force、フックの省略も明示指示がある場合のみ。
- フック失敗は原因を直して通常のコミットを再試行する。無関係な変更や機密ファイルは含めない。
- 完了時はコミットIDと要点、未完了事項があればその理由を報告する。

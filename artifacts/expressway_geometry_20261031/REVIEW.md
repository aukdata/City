# 高速道路の曲率上限・変速車線（加速・減速車線）

2026-10-31。依頼: 高速道路の曲率が急すぎる箇所に上限を設ける。合流車線・加速車線を設ける。鋭角に交わる道路の描画を直す（別スレッドの修正を取り込み、1 コミットにまとめる）。

## 修正前の測定

テスト `Expressway.GeneratedTerrainSeeds` に線形の監査を足して測った（seed 42 / 7 / 20260316、一般道なし）。

- 本線の最小曲線半径: 141m / 114m / 103m（基準 460m = 設計速度 100km/h）。回廊の折れを均す処理が、点の間隔が縮むと進まなくなっていた。
- ランプ: IC の遠い側の流入ランプ（ループの外を回る区間）が半径 50m（設計速度 50km/h の基準 100m）。
- 合流・分流: ランプは本線の走行車線へ直接つながり、変速車線がなかった。

## 変更

- 曲率（`src/gen/ExpresswayNetwork.cpp`）
  - 中心線の 3 点おき（240m）の外接円で半径を見積もり、460m×1.15 を割る点の前後だけを繰り返し均す。均しても残る箇所は均す幅と参照する点の間隔を広げ、8 回ごとに弧長で等間隔へ取り直す。
  - 車道の曲線は節点どうしの向きではなく中心線の接線から作る。分合流点で節点の間隔が不揃いでも曲率が跳ねない。変速車線の始終点は、他の節点から 40m 以上離れるときだけ節点にする。
  - 設計速度ごとの最小曲線半径 `ExpresswayNetwork::minimumCurveRadius`（道路構造令: 40km/h→60m、50km/h→100m、60km/h→150m、100km/h→460m）を IC の形の判定に加えた。遠い側の流入ランプはループの外を半径 110m の 1/4 円で回る。PA/SA の出入口は半径が足りるまで駐車場沿いの通路を短くする。
  - 支線（JCT）は最小曲線半径を守れなければ作らない。本線は必ず通す。
- 変速車線（`ExpresswayCrossSection.hpp`, `ExpresswayNetwork.cpp`, `expressway.json`）
  - IC・PA/SA・JCT の分流点の手前に減速車線 110m、合流点の先に加速車線 200m を本線の左（路肩側）に足し、それぞれ 70m のすり付けで幅を 0 へ絞る（平行式）。路肩・防護柵・法面はその分外へ出る。本線車線との境は破線。
  - ランプの本線側の端は変速車線の中心へ寄せ、本線側の路肩・防護柵はその端で幅 0 に絞る。
  - 変速車線に掛かる案内標識は、変速車線の幅だけ路肩側へ寄せる。
- 車線接続（`src/road/RoadNetwork_Connections.cpp`）
  - 自動車専用道の一方通行どうしの節点では、交差点の方向別配分ではなく、本線の向きに直交する横位置が近い車線どうしをつなぐ。合流ランプは加速車線へ、分流ランプは減速車線から出る。
- 最後の計画（土被りの上限なし）でも縦断が解けないときは、地図端の端点の高さを固定せず、地盤に近い高さから順に試す（実ゲーム seed 42 で本線が通らなかったため）。
- 鋭角交差の描画は別スレッドの修正を取り込んだ（[acute_junctions](../acute_junctions/REVIEW.md)）。

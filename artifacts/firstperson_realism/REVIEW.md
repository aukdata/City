# 一人称写真を基にした街並みの改善

2026-09-13。実ゲームを起動し、通常の一人称カメラで商業街路・都市住宅街・農村集落を撮影。松本の中町通り、谷中の住宅路地、美山の集落、保存済みの神田の街並みと比較した。出典・観察・優先順位は [ANALYSIS.md](ANALYSIS.md) にまとめた。

## 比較から反映したこと

- 路面：茶色く均一な印象を抑え、灰色の骨材、細かな凹凸、色むらと舗装補修を加えた。歩道には実寸の目地、道路際には排水桝と点検蓋を追加した。
- 建物の足元：基礎に誤って葉の材質が使われていた不具合を修正した。入口の側枠・段差、郵便受け・インターホン、植木鉢、店舗の庇・看板・メニューボード、駐輪自転車を追加した。
- 壁面への接続：全体のAABBを使うと庇やバルコニーの分だけ入口が浮くため、42モデルの1階壁面と窓枠の張り出しをOBJから測定。入口の側枠に奥行きを持たせ、窓台をまたいで壁へつなげた。
- ガラス：既存の窓テクスチャに視線依存の控えめな空反射を加えた。周囲の建物を正確に映す反射や店舗内部は未実装。
- 樹木：近景の大きな葉の塊を小さい不規則な葉群にし、幹・枝と葉の陰影を調整。遠景のひし形状の輪郭も改善した。遠景は近景より三角形数を96〜99%削減する。

## 撮影と再現方法

新規シード42、13時、1920×1080、目線1.5m、通常のFOV80度。同じ道路ID・座標・向きの6視点で比較。各視点で読み込みを待ち、末尾60フレームを集計した。道路・建物の生成結果は変更していない。

```powershell
# Appを作業ディレクトリにして実行。撮影終了時に自動終了する。
.\City.exe --capture-first-person --seed 42 --new
```

写真は `verification/before_00.png`〜`before_05.png`、`after_00.png`〜`after_05.png`。元データの参照写真は `references/`。画像はチャットに埋め込まず、ローカルファイルとして保存している。

## 検証結果

- Release本体・Testビルド：コンパイラエラー・警告なし。
- **77 / 77 テスト成功**。一人称の高さと移動方向、入口設備の実寸・接地・接続範囲・インデックス、全都市シェーダーのコンパイル、歩道の目地とアスファルト色のGPU読み戻しを含む。
- 撮影座標、描画時間、実行ファイルのSHA-256は `measurements.json`。テスト結果は `test_results.json`。
- 改善途中の実ゲーム画像は実写と目視比較した。画像送信エラーの再発後、最終のGPUメッシュ共有への変更はファイル保存と画像差分・ログの確認に限定している。最終画像をチャットへ読み込む目視検査は行っていない。

### 同じ6視点の描画時間

単位ms、CPUは描画区間の中央値。VSync有効で画面転送を含むフレーム時間は13.3ms前後と26.8ms前後へ分かれる。撮影中に別ゲームの起動状況が変わったため、この表から速度改善は判定しない。GPU単体の所要時間でもない。移動性能の比較は下記の単独実行を参照。

### 移動時の負荷

新規シード42・同じ720フレームの移動経路で、他のゲーム起動がないことを確認して順番に実行した。比較元は変更前の実行ファイルと変更前のシェーダー。実装途中では店先の街区一括生成に102.19ms、フレームCPUに123.56msの停止を記録したため採用を取りやめた。最終版はモデルごとに6種類のGPUメッシュをロード時に作成し、110m以内だけ共用して描画する。該当区画の再構築は最初の再計測で5.21msへ減少した。

| 指標 | 改善前 | 最終版 |
|---|---:|---:|
| CPU中央値 | 5.00ms | 5.07ms |
| CPU 95%点 | 17.84ms | 18.29ms |
| CPU最大 | 38.06ms | 40.11ms |
| CPU 100ms超 | 0回 | 0回 |

結果はこの経路・1回ずつの計測であり、全マップ・全状況で一定FPSを保証するものではない。CSVと要約を同梱した。

## まだ実写との差が残る点

歩行者の活動、店舗内部、建物の用途や年代による1階の造り分け、葉を個別に表現する近景素材、既存モデルに焼き込まれた粗い陰影には改善余地がある。今回の反映は歩行目線で目立つ材質・接地・店先の設備を中心とし、完全な写実表現を達成したとは扱わない。

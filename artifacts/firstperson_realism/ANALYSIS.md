# 歩行目線の実写比較

2026-09-13。実ゲームの通常歩行カメラを地面から1.5 m、13時、1920×1080に固定。商業街路、都市住宅街、農村集落の両方向を撮影し、同じ座標で変更後を比較する。撮影専用に建物や路面を差し替えず、通常描画を使用する。

## 比較写真

- [神田の街並み / Photock](https://zh-cn.photock.org/photo/kanda-streetscape)：前回保存した写真も再確認。狭い道路に面する建物、袖看板、店先の品物、自転車、配線、舗装補修とマンホール。望遠寄りの写真なので見かけの密度をそのままゲームの距離へ変換しない。
- [中町通り / 松本市公式観光](https://visitmatsumoto.com/spot/detail_1082.html)：今回取得した写真。歩道の目地、排水スリット、縁石、マンホール、植木鉢、庇、入口の陰影を確認。夕方の写真なので色温度の完全一致は狙わない。
- [谷中地区 / 台東区](https://www.city.taito.lg.jp/kurashi/kyodo/tyoukai/11tiku/yanaka/)：今回取得した住宅路地写真。低い塀、側溝、樹冠による遮蔽、電柱、路面の色むらを比較。掲載画像は240×320で細部の判断に限界がある。
- [かやぶきの里 / 京都美山ナビ](https://miyamanavi.com/sightseeing/kayabuki-no-sato)：今回取得した集落写真。道路と庭の境界、大小の植栽、樹冠の不規則性、山林の層を比較。やや高い位置の写真であり、道路幅の定量比較には使わない。

写真は参照用として保存し、ゲームの配布アセットに流用しない。実在店舗の看板やロゴを複写しない。

## 改善前の観察と優先順位

| 優先度 | 実ゲームで確認した不足 | 実写との違い | 実装方針 |
|---|---|---|---|
| 高 | 歩道が無地の長い板、道路際が黒い一枚の帯に見える | 舗装目地、排水桝、側溝蓋、縁石の継ぎ目がある | メートル基準の舗装シェーダーと立体の排水設備・マンホール |
| 高 | 樹冠がひし形・三角形の反復になっている | 輪郭が不規則で、葉群の大きさと枝ぶりが異なる | 近景の枝葉と遠景の輪郭を作り直し、葉の陰影と距離別負荷を検証 |
| 高 | 大きい建物が並んでも1階の情報量が少ない | 庇、店舗看板、入口、植木鉢、自転車が歩行者の目線に集中する | 建物の接道面へ種類別の店先・玄関設備を追加 |
| 高 | 建物の基礎が植栽と同じ緑色の材質になっている | 基礎は地面と建物をつなぐコンクリート面として読める | 基礎の材質キーを分離して修正 |
| 中 | 窓がほぼ同じ暗い青の面になっている | ガラスには空の反射と室内の暗さが共存する | 建物専用の控えめな視線依存反射を追加 |
| 中 | 路面が茶色く均一で、新しい舗装しかない | 灰色の骨材、補修跡、色むらが細かく重なる | 元の写真素材を保ち、色と細部を路面専用に調整 |
| 継続 | 人の活動、車や自転車の動き、店舗内部が少ない | 生活の密度が街路の印象を作っている | 今回は自転車など静的な店先を先行。歩行者の行動シミュレーションとは分ける |

## 比較の基準

目線と向きが一致する前後画像、撮影地点のログ、CPU描画とフレーム時間の60フレーム集計を残す。シェーダーや色を変えただけで写実性を達成したとは判定しない。近景の輪郭・材質・接地と、遠景への負荷を別々に確認する。

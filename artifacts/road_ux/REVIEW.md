# 道路敷設 UX 改善（2026-09-12）

前回までの街並み素材を `5aa9f69`、道路・生成・描画・性能の改善を `1eecd79` にコミット後、道路計画モードを改善した。

## 操作と表示

- `R` で道路パネル。生活道路・2車線サブ幹線・4車線幹線・一方通行を選択。
- クリックごとに区間を延長。直線 / 地形に沿う自動経路を選べる。
- 水色で確定済み計画の幅員、白い点線で次の区間、緑で接続先を表示。自動経路モードのマウスガイドは直線距離であることを明記。
- `Shift` は45度刻み、`Alt` は接続の一時解除。既存ノードと長い道路の途中へのスナップに対応。
- 右クリック / Backspace / Ctrl+Z で戻す、Ctrl+Y / Ctrl+Shift+Z でやり直す。終点だけの調整にも対応。
- 保存前の延長・費用・工期を表示。Enter で保存し、一覧の着工ボタンで施工開始。保存には資金を使わない。
- Esc は仮計画を破棄し、再度押すと終了。文字入力中のショートカット誤発火を抑止。Ctrl+Z がゾーン塗りに切り替わる不具合、クリック位置が前フレームになる入力順も修正。

## 既存道路を守る処理

仮計画は独立した RoadNetwork を使い、既存の道路・地形・経路探索を変更しない。保存は一時コピーへ全区間を追加して成功した場合のみ反映する。接続失敗時は途中の道路分割も反映しない。連打で2m未満の短区間を作らず、10mの道路は経路探索セルの大きさによらず作れる。

既存の路線・工事計画を持つ道路への接続で、元の300mの計画が200mになる不具合を回帰テストで再現（join_before.json）。道路分割を撤去として扱わず、路線のID・名称・順序と計画を維持するよう修正。逆向きに辿る路線と1区間だけの路線も検証した。

## 検証

- Release 本体・Test をビルド（警告・エラーなし）。
- Test の共有ツールバーを3状態で撮影・レビューしてから本体へ組み込み。画面: `Test/App/Screenshot/road_plan_toolbar.png`。
- 実ゲームを `--capture-road-ux --seed 42 --new` で起動。開始・2点・3点・Undo・Redo・保存の6状態を `runtime/Screenshot/road_ux_*.png` に撮影。
- ゲームで105mの計画を保存し、プレビューと保存後の延長一致を確認。

- 編集したC++ファイルはUTF-8 BOM + CRLFを保持。

## 現時点の制限

経路上の建物の自動撤去、用地取得・撤去費、途中で横切った道路の自動交差処理は未対応。接続は既存道路上の点を指定して行う。プレビューの道路幅は確認できるが、建物の撤去予定表示ではない。Undo/Redo は編集中の仮計画が対象で、保存済み計画は一覧から削除する。保存時には道路網の反映とシミュレーション更新の処理が発生する（実測は verified_results.json）。

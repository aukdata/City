## リアル調への変更

- Poly Havenの漆喰・木材・レンガの実写拡散色素材を追加。既存のコンクリート素材も再利用する。漆喰は塗装色を混ぜて汚れの強さを抑える。
- 壁・屋根のUVを建物全体へ引き伸ばさず、メートル単位で反復する。漆喰は0.65m、レンガ等は2mを基準にする。
- 窓枠、庇、バルコニー、外階段、薄い手すり、配管、雨樋、屋根材、室外機、物干し金具をメッシュで構成する。
- 低層モデルの角に12mmの面取りを施す。中高層住宅には一律の面取りを適用せず、幾何量を抑える。
- Blender/Cyclesで拡散色と0.48m範囲の局所AO（接合部の陰影）を焼き込む。直接光や特定時刻の影は焼き込まない。
- 完成モデルは各1マテリアル、1枚の焼き込み画像。通常は1024×1024、中高層住宅とオフィスは2048×2048。Siv3D既存のOBJ描画経路で表示できる。
- 不透明のガラス表現を使用する。室内、透明ガラス、独立した粗さ・法線マップのゲーム側対応は追加していない。

## 配置・ゲーム側

OBJはY上・正面-Z・メートル単位・地表Y=0。BlenderではZ上・正面+Y。モデル本体、庇、設備、外階段を含めて1区画内に収め、既存の用途別幅制限を適用する。

戸建ての描画高さ上限を4mから8.5mに変更し、2階建てが不自然に縮まらないようにした。人口や用途地域などのシミュレーション値は変更しない。

選択候補数は戸建て8、低層住宅4、中層住宅3、高層住宅3、店舗6、オフィス4、工場4、公共施設4。セーブ形式・種類IDは変更せず、既存セーブの見た目にも反映する。候補数変更により、同じセルで選ばれる見た目が以前と変わる場合がある。

診療所・消防団・交番・図書室などは既存の公共施設カテゴリの外観違いであり、医療・消防・警察等の個別シミュレーション機能は追加しない。

## 制作データと再生成

```powershell
# 外部ダウンロードが必要な初回のみ。著者・URL・ハッシュを同時記録。
python scripts/download_realistic_materials.py
# モデル構築ソースJSON、元マテリアル画像を生成。
python scripts/build_realistic_town.py
# Blenderで仕上げ、UV展開、焼き込み、ゲーム用OBJ書き出し、前後レンダー。
& 'D:/Program Files/Blender Foundation/Blender 4.5/blender.exe' --background --python scripts/finish_realistic_town_blender.py
# 書き出されたOBJ/MTL/画像の検証と一覧画像。
python scripts/verify_realistic_town.py
```

Python 3、NumPy、Pillow、Blender 4.5を使用。旧 `generate_detailed_buildings.py` とPowerShellの簡易モデル生成スクリプトは第1弾以前の原型用なので、このパックを再生成する場合は上の手順を使用する。

編集用 `artifacts/realistic_town/realistic_town.blend` は全24モデル、焼き込み画像、撮影用照明・カメラを内蔵する。ギャラリーの配置はオブジェクト移動として保存され、メッシュは原点基準。ゲームへ再書き出す際はギャラリー配置を外し、Y上・正面-Zで書き出す。

`realistic_manifest.json` にゲーム用のパス、寸法、三角形数、テクスチャサイズを記録。`artifacts/realistic_town/contact_front.jpg` / `contact_back.jpg` はモデル単体のBlenderプレビューであり、実ゲーム画面ではない。

# 道路・日本の街並み・移動時の停止の改善

2026-09-12。Siv3D 0.6.16 / Windows x64 / Release。

## 変更内容

- **縁石の穴**：OBJ読み込みが連続した空白を空の座標として扱い、縁石の頂点を潰していた。空トークンを除外し、8枚の三角形の面積を回帰テストで確認。
- **交差点**：進入路の幅に応じた切り詰め、鋭角で重なる車道による側帯の切り抜き、接続点移動時のBezier接線維持を実装。近接交差点を過剰に統合しない。
- **区画線**：短い道路でも生成し、2本接続のIntersectionを通して補間。路面へ投影し、鋭角で重なる別進入路へ線を伸ばさない。交差点の中央に通常の中心線を引くこととは区別する。
- **路面**：灰色のアスファルトと2m周期のUV。歩道・縁石の材質色をHDR照明に合う線形色へ変換。
- **道路階層**：城下町型の市街地に4車線50km/h、2車線40km/hの幹線・補助幹線、25km/hの生活道路、方向を交互に変えた一方通行を生成する。
- **建物密度**：道路があるグリッドの角まで用途を指定し、街路に面する建物の配置間隔・寸法を調整。都心は中高層と店舗を混在させ、店舗のまとまる街区を生成する。
- **モデル**：日本語の看板・袖看板・自販機・室外機・配管・メニュー板を持つ雑居ビル4種と、小店舗が並ぶ2〜3階建て2種を作成。全48バリエーションと遠景モデルをロード時に読み込む。
- **電柱**：円形で先細りの柱、腕金、碍子、変圧器、取付帯、足場ボルト、配線を追加。
- **田園・里山**：農地の畦、平坦な水田、作物による色差、農村の屋敷林、道路・宅地を避ける斜面の森林を追加。広葉樹と針葉樹を群落として配置する。

[実際に閲覧した写真と反映内容](photo_references/REFERENCE_NOTES.md)には神田、新宿ゴールデン街、松本、砺波、美山の出典を記載。写真自体はゲーム素材へ転用していない。

## 移動時の処理時間

シード42、1280×768、13時、一時停止、VSync有効。ロード後に5m/フレームで3.6km移動する同じ720フレームの経路を使用。初期生成・ロード時間は含めない。

| CPU処理時間 | 改善前 | 最終候補 |
|---|---:|---:|
| 中央値 | 5.04ms | 5.91ms |
| 95パーセンタイル | 23.41ms | 22.43ms |
| 99パーセンタイル | 132.49ms | 28.36ms |
| 最大 | 197.93ms | 41.68ms |
| 40ms超 | 17回 | 1回 |
| 100ms超 | 13回 | 0回 |

これは今回の外観変更も含めた改善前後比較で、単一変更だけを比較する試験ではない。平均的なフレームの軽量化より、突発的な停止の低減が主な成果。

実測で切り分けた原因と対策：

1. 60フレームごとに約1,677万セルを走査していた住宅数HUD集計。チャンクごとの増分集計へ変更し、更新時は約1.1〜1.7msへ低減。
2. 地形の道路切り抜き・敷地メッシュ生成を最大2ワーカーへ移動。不変スナップショットを使い、古い結果を世代番号で破棄。GPUへの反映は1チャンク/フレームに制限。
3. 道路20630の側帯切り抜きが隣接舗装の全三角形を繰り返し走査していた。空間索引と境界ボックス判定を入れ、同道路の生成は175ms前後から22.68msへ低減。

生データ：[比較JSON](performance_comparison.json)、[改善前CSV](sync/streaming_frames.csv)、[最終候補CSV](release_flight/streaming_frames.csv)、[最終候補ログ](release_flight/debug.log)。CPU処理時間は画面転送待ちを含むフレーム全体のGPU時間ではない。森林の最後の外観調整前の計測もfinal_flightに保持している。

## 検証

- 常設テスト20/20成功：[結果JSON](../../Test/App/TestResults/results.json)。

- 2本接続の傾斜したIntersectionで中心線・路端線の63/63サンプルをGPU描画から確認。

- 本体撮影は `final_capture/Screenshot/city_generation/`（シード42）、`final_capture_20260316/Screenshot/city_generation/`（シード20260316）に保存。里山・地方市街地を含む各26視点。後者は森林の最終分布調整を含む。

## 適用と残る範囲

道路の描画・モデル・材質改善は既存データにも適用される。道路階層や新しい地区構成を一通り見る場合は新規生成を使う。元の保存データには今回の検証用の上書きをしていない。

検証済みRelease実行ファイルをApp/City.exeへ反映し、`--seed 42 --new`で通常起動した。[起動記録と実行ファイルのSHA-256](launched_game.json)。

写真同等の写実性、歩行者の賑わい、店舗別の夜間発光、季節ごとの水田表現は今回の到達点に含まない。広域で常時60fpsは未達。従来から記録されている特定シードの海岸道路の水没、車両挙動の問題は `ISSUE.md` に残している。

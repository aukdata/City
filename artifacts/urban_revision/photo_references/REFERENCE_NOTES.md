# 日本の街並みの写真参照

2026-09-12。実際の写真を閲覧し、密度・高さ・素材・土地利用の違いをモデルと生成ルールに反映した。写真は検証資料であり、ゲーム配布用テクスチャとしては使用していない。

## 実装

- `scripts/build_japanese_streets.py` はオリジナルOBJと共有アトラスを生成する。看板名は架空のもの。OSの日本語フォントをラスタライズし、フォントファイルは同梱しない。
- `WorldRenderer` の森林・区画外構は不変スナップショットからワーカーで生成し、GPU転送は毎フレーム1チャンクまで。森林は固定の16 mサンプルと座標ハッシュで再現可能にする。
- 地区ごとに幹線・補助幹線・生活道路・一方通行の階層を作る。都心の商業街区は店舗の比率を上げ、高層一辺倒にならない構成にする。
- 写真そのものや実在店舗のロゴはゲームアセットへ転用していない。

## 再現の範囲

今回の段階は、日本の街角・田園・里山の構成をプロシージャルな3Dへ反映したもの。写真同等の写実性、歩行者による賑わい、夜間の各店舗の発光、季節ごとの水田表現は未実装。美山の茅葺き住宅を全国の農村へ一律に置くことはしていない。

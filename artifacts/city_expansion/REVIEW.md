# 街区の密集化・鉄道・水域横断・全画面マップ

2026-09-13。既存セーブの維持を前提にせず、新規生成を対象に実装・検証した。

## 変更した動作

- 大きい格子の内側に幅4.4mの細街路を追加し、隣接街区と共有する接続点で既設道路につなぐ。生活道路の断面として、歩道・中央線を設けず側溝と路肩を付けた。
- 実道路グラフから閉じた街区を取り出し、建物のない都市街区へ接道する建物を補充する。農地や駐車場だけでは充足としない。海岸の低い街区は計画全体を縮小して避け、補充時も接道・道路／鉄道干渉・水際の条件を守る。斜面の低層建物には基礎を描く。空街区が残れば生成検査は不合格になる。
- 鉄道を駅の近接関係と地形に基づいて引き直した。道路横断・都市部は高架とし、路盤・床版・側壁・橋脚を追加した。駅間の全区間を列車の経路に含め、逆向きの辺・閉塞待ち・駅停車も処理する。建物は鉄道帯を避ける。
- 最終道路形状で水域を検査し、必要区間を分割して橋へ変換する。端点を共有して取付部をつなぎ、岸を越える高さを確保する。旧版シード42の水没97辺に対し、最終版は0辺。
- `M` またはミニマップから全画面マップを開く。ホイール／＋−でズーム、左ドラッグで移動、右クリックの「ここへジャンプ」で移動、`Esc`で終了。道路・鉄道はベクター表示し、操作は背後へ流さない。
- ローカルの標識資料を参照して、最高速度・一方通行・曲線警戒を追加した。欠落していた円形／逆三角形の板モデルも補った。案内標識の交差点除外は維持する。

| 42 | 5,384 | 0 | 59,251 | 21,996 | 0 | 0 |
| 20260316 | 5,864 | 0 | 64,162 | 23,021 | 0 | 0 |

両シードとも、接道先欠落、敷地欠落、道路侵入、接道距離、水際建物の検査違反は0。最終補充で11／5街区を埋めた。鉄道は18／20駅、933／1,017区間。最大実勾配は23.88／22.42‰。

常設回帰テストは **67件成功、失敗0件**。街区面抽出、水域横断、逆向きの始発線路と中間駅間の走行、標識モデル／アルファ、地図座標変換・ズーム・ジャンプを含む。

本体を起動して街並み、街角、駅、橋、全画面地図、拡大地図とメニューの6画面を保存した。全画面地図への遷移とメニューからの実カメラ移動が成功し、22,929本の道路・鉄道ストローク、398ラベルを登録した。画像はチャットへ返さず、ローカルPNGのサイズ・色分布と実行ログで描画の成立を確認した。人間の目による美観評価とは異なる。

機械可読結果は `verification/summary.json`、テスト全件は `verification/tests.json`、生成・描画ログの要点は同ディレクトリのTXT。PNGも同所へ集約した。道路の橋脚干渉キャッシュは道路変更通知で破棄し、辺数が変わらないノード編集にも追従する。

## 再現

ビルドはルートのAGENTS.mdに従う。実行時の作業ディレクトリはApp（独立検証ならassets／engine／shadersを参照する専用ディレクトリ）とする。引数解析の都合で検査オプションを`--new`より前に置く。

```text
City.exe --audit-road-integrity --seed 42 --new
City.exe --audit-road-integrity --seed 20260316 --new
City.exe --capture-transport --seed 42 --new
```

生成検査は`road_integrity_snapshot/`を出力して終了する。保存した道路と地形の検査は、リポジトリルートから次の通り。

```text
python artifacts/city_expansion/audit_water.py <snapshot-directory> <output-directory>
```

このスクリプトは`artifacts/road_integrity/audit_save.py`のセーブ読取部とNumPyを使う。Testは常設ケースを含む通常の実行で自動終了する。描画検査は`Screenshot/transport_00.png`〜`05.png`を出力して終了する。

## 検査範囲と整理

結果は上記2シードと有限間隔のサンプリングに対する値であり、全シード・全ての微小な地形変化を証明するものではない。既存の車両挙動と広域描画性能の課題はISSUE.mdに残す。今回の並行実行時間からFPS改善は主張しない。鉄道の自動生成は簡易ダイヤで、行き違い設備の自動設計まで含めない。

過去の検証用ゲームコピー、セーブスナップショット、ソース書換え用の一時スクリプト、Blenderの再生成可能な作業ファイル、ダウンロードした検証用Pythonライブラリを整理した。本番アセット、素材の出典、`scripts/`の再生成処理、研究と検証結果は保持した。削除時は絶対パスと追跡ファイルを検査し、assets等のジャンクションはリンクだけを外してから実行環境を削除した。ユーザーのApp/savesには手を加えていない。削除一覧と回収容量は`cleanup.json`。

古いレビューが参照する一時実行ディレクトリは整理対象に含む。最新版の判断にはこのレビューと`verification/`を用いる。

一部の旧画像・素材テクスチャの追加一括削除は、自動承認レビューで対象確認不足と判断されたため行っていない。これらと残る中間JSONはローカルに保持し、再生成物としてGitの対象から外した。削除済みの範囲はcleanup.jsonのみが示す。

# 生成設定・LOD・大量交通の検証記録

2026-09-16。Windows x64 / Siv3D 0.6.16 / Release。画像はローカル保存と数値解析だけで検証し、会話へ送信していない。

## 実装

- 19分野・837個の生成調整値を App/assets/generation/ へ移動。型・範囲・関連値を検査し、一度だけ読み込む。実装定数との区別は同フォルダーのREADMEに記載。
- 全88個の元OBJに中景・遠景モデル。元939,099三角形に対し遠景94,920（10.1%）。建物を材質別に結合し、車は256台単位で変換行列をGPUへ渡す。電車・信号・標識支柱・工事車両にもLOD、駅・車庫には簡略メッシュ。
- 通常車は接道する建物前の車線で出発・減速・到着。標準上限12,000台。画面外でも渋滞を計算し、個々の車のログは廃止。

## 検証結果

- 本体・TestのReleaseビルド成功。最終 build_signals_verified.log は警告0・エラー0。
- 常設テスト **201/201成功**。full_tests_final.json。
- generation_schema.py --check: 全837項目の値・スキーマ・コード参照が整合。
- 地形設定移行の20シードは標高データが移行前後で一致。地形・都市生成の常設検査も成功。
- 全LODのロード・寸法・原点・材質参照を検査。通常描画とのGPU比較も成功。257台の変換比較は可視29,146ピクセル、平均チャンネル差0。
- 信号は絶対パスからLODを解決し、全段階に灯器を維持。500m境界の表示と範囲外の非表示をGPU読み戻しで検証。
- 画面外の12,000台を90秒停止させる検査: 全台数を維持、最小バンパー間隔2.0003m、更新中央値1.69ms。
- 12,000台を全車表示（1280×720）: CPU中央値1.122ms、GPU0.2766ms、144描画呼び出し。空の次フレームに前の車が残らないことも確認。
- 車線の前後検索（12,000台）: 総当たり46.547ms、索引0.315ms。同じ検索結果を比較。

## 本体の実測

シード42、1280×768、駅0付近。注視点(14231.84397, 43, 26222.88595)、距離3000m、yaw=-0.7、pitch=0.72。旧実行ファイルもApp内へ置き、アセットの参照先を揃えた。他のGPUテストと同時実行していない。

停止中の比較はゲーム内8.640784時間、同じ視点・時刻、ウォームアップ後800フレームの中央値。

| 指標 | 変更前 | 変更後 |
|---|---:|---:|
| 描画処理 | 6.766ms | 4.001ms |
| 地形・建物の描画区間 | 2.096ms | 1.128ms |
| フレーム間隔 | 13.396ms | 13.366ms |

描画処理は約40.9%短縮。フレーム間隔は表示側の約75fps付近で変化が小さい。旧版には車台数の計測列がなく、交通量を揃えた更新処理の比較ではない。停止中のcarUpdateMsには最後の更新値が残るため、停止フレームの実行時間として扱わない。

新しい街を8時から通常速度で動かし、9,000台を超えた2654フレームでは中央値9623台・15.439ms（約64.8fps）。車の更新7.867ms、車の描画0.079ms、画面内約697台・18呼び出し。接道建物36,058箇所。終了直前まで2,939件の建物間到着、経路失敗0を確認した。

上記はこのPC・視点での実測値。gpuMsは計測対象の描画区間であり、GPUフレーム全体ではない。詳細は performance_summary.json と comparison_*_frames.csv。

同条件のローカル画像比較（旧 App/Screenshot/playtest_command_3.png、新 playtest_command_2.png）は1280×768。RGB平均絶対差0.507 / 0.510 / 0.401（0〜255）。低詳細化で全体の構図が失われていないことを補助的に確認。形状は常設GPU検査で確認。

## 作業ツリーとコミット

開始時点から多数の未コミットの機能変更があったため、開始時のテキストをbaseline.zipに退避し、既存変更を保持した。独立した設定・LOD資産・共通部品・常設検証は機能単位でコミットする。既存変更と同じファイルへ行った統合部分は、以前の変更を巻き込まないよう作業ツリーに残す。検証対象は統合済みの作業ツリー全体とApp/City.exe。

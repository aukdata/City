# 生成設定・田園道路・地下鉄道操作の検証

## 対応範囲

依頼と対応表は [CHECKLIST.md](CHECKLIST.md)、現行仕様は [33章](../../plan/33_generation_and_underground.md)。新規地形・集落生成、畦道と村間の接続、開始UI、保存一覧、鉄道選択、地下断面を変更した。既存セーブの移行は行っていない。本体は起動せず、独立したTestで検証した。画像はローカル保存とGPU readbackのみで、会話へ送信していない。

## 計測から直した仕様の不整合

| 発見 | 対応 |
|---|---|
| 自動生成を外してもロード時に田畑等を再生成する可能性 | GenerationOptionsを保存と再構築で共有 |
| 自動車を無効にしても歩行者が自動車移動を選ぶ | 自動選択と明示的Car指定を徒歩へ揃える。車両更新は止めず自動発生の目標台数を0にする |
| 自動鉄道なしの街で追加線路が別グラフになる | シーン初期化時から共通道路網へbind |
| 列車追跡が地図ジャンプ・カメラコマンド後にも続く | 移動操作で追跡を解除。文字入力とポーズは車の追跡にも共通適用 |
| 地下表示で地上モデルや別階の選択が混ざる | 土被りによる路盤・駅のメッシュ切出し。同じ形状で選択と黄色輪郭を作る |
| 地下計画のガイドが地表へ浮く | ガイドの高さを地下作業面と共有 |
| 地形編集の上限350mに高山が強制的に落ちる | 編集範囲−2,000〜6,000m、地形変更で地下キャッシュも更新 |
| 駅名の「駅」が二重になる／規模を[城][宿]と表示 | 駅接尾辞の重複回避、規模を[市][町]へ統一 |
| 旧仕様書の高架・トンネル費が実装と異なる | 00・03・26章を現行の64＋高さ／128＋長さの費用へ統一 |
| 地下切替がFPSグラフに重なる | Testで移動先を検証し、グラフ表示時だけ上へ移動 |

## 地形と生成時間

同じシード42、中央16×16チャンク（約108万格子点）の地形構築を比較。従来の重い海岸・山脈ノイズを64m格子に事前計算し、16m地表から補間する。詳細ノイズ、河川、道路の地形追従は維持する。

| 項目 | 変更前 | 変更後の代表値 |
|---|---:|---:|
| 事前準備 | 9.945 ms | 56.225 ms |
| 256チャンク構築 | 340.870 ms | 81.662 ms |
| 合計 | 350.815 ms | 137.887 ms |

この区間の合計は約61%短縮。**新規ゲームの待ち時間全体の改善率ではない。** 鉄道候補の5番目では、解析曲線で上書きするため破棄していた粗い経路探索も省いた。都市数上限も後続処理の対象を抑える。鉄道・建物・描画準備を含む本体の総ロード時間は今回測定していない。

- 7シードの256×256ずらしサンプルで平野系面積は約28〜36%、全て50%以下。
- 20シードで中央の乾いた適地の平均47.9%、外周の海・山の平均70.9%。中央の山、大湾、内陸湖と平野の変化も残る。
- 適地を多数置く3シードで都市は最大4。
- 450mの狭い谷底（耕作可能な方向2/12）で山村の成立を確認。
- 旧回帰の山頂上限2,200mは新地形に合わず、日本の山としての検査を3,777m未満へ更新。計測4シードの最高標高は約1,890〜2,403m。
- 標高2,048m以上ではfloat格納の1ULPが約0.244mm。旧0.1mm検査を「同じ三角形平面をfloat格納精度に丸めた値と完全一致」へ変更し、実際の地面とサンプリングの一致は緩めない。

## 道路と操作

- 村間テスト: 直線500mに対して道路3,500mのU字迂回。12〜19回の試行から追加道を生成し、実ネットワークの距離が750m未満へ短縮。再実行で重複道路を作らない。
- 完全な平地: 農道169区間中119区間が水平方向に屈曲し、6か所で接続。
- 畦道の行き止まり: 150m離れた別の道へ接続し、終点の接続次数が1から2に変わる。
- 地形のある田園: 70区画、曲線区間116、接続10、最大勾配2.39%、全農道が既存道から到達可能。村近くの農地密度7.58%、遠方0.68%。
- 地下テスト: 同じXZ座標に地上道と地下道を配置し、地下だけを描画・選択。地下駅5材質部品が地表境界で切れ、GPUで5,877画素を確認。
- 列車追跡: 先頭車両の弧長を100m動かしたとき追跡位置も同じ距離移動する。
- 保存削除はTestResults内の専用フィクスチャだけを使用。隣の保存を残すことと不正な親パスの拒否を確認。
- UIのチェックボックス・削除確認・列車情報・地下切替はTestで先行確認。初回5件とFPS移動後11件の結果をそれぞれ保管。

## 制約

村間接続は有限範囲・有限展開の共通線形探索。合法な接続が存在しても探索上限で見送る場合がある。最寄りの道路が畦道の勾配・曲率・水域等に不適合な場合も強制接続しない。地下は編集用断面表示であり、地図のレイヤー切替や坑内照明の物理シミュレーションではない。

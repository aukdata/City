# 日本の街並みモデル・第1弾

> 第1弾の形状・制作経緯の記録です。現行モデルはリアル調素材で更新済みです。現在のモデル一覧、テクスチャ、再生成方法は [REALISTIC_PACK.md](../REALISTIC_PACK.md) を参照してください。

## 選定理由

制作前は住宅10種に対して店舗は単純な箱の組み合わせ3種で、工場と公共施設はオフィス2種を流用していた。用途の読み分けと道路沿いの生活感を優先し、店舗3種を作り直し、工場・公共施設に各2種の専用モデルを追加した。

| shop_002.obj | 昔ながらの米屋「KOME」 | 切妻屋根、屋根目地、棟、木格子、暖簾、商品台、雨樋 | 1,592 |

名称・意匠は架空。診療所のマークは緑色で、赤十字標章は使用しない。

## ゲームへの接続

- `BuildingType::Shop` → `shop_001`〜`003`（既存の選択規則を維持）。
- `BuildingType::Factory` → `factory_001`〜`002`。
- `BuildingType::PublicFacility` → `public_001`〜`002`。
- `BuildingType::Office` → 既存 `office_001`〜`002`。
- 全モデルを既存ローダーの `commercial/` 配下に置く。新規施設の専用ゲーム機能を追加するものではなく、既存の建物種別に対する見た目のバリエーション。
- セーブ形式や建物種別IDは変更しない。描画時に種類と座標から選ぶため、既存セーブにも反映される。
- メートル単位、Y上、道路側が-Z、地表がY=0。TOMLは `scale=1.0`、`setback_from_road_m=1.8`。既存描画の用途別最大幅・最大高さへの縮小を適用する。
- モデル全体（看板・庇・室外機を含む）を最大8m未満に収める。工場・公共施設は約6.5m四方。

## テクスチャと制作データ

`town_atlas.png` は1024×512の共有拡散色アトラス。壁タイル、木目、金属、ガラス風反射、看板を決定論的に生成する。全7モデルが各1マテリアル・1オブジェクトを使い、OBJには三角形、UV、面法線を明示する。ガラスは不透明で、透明ソートや内装描画を必要としない。現段階で専用LODは追加していない。

外部テクスチャのダウンロードは行っていない。出所は [ORIGINAL_TOWN_ASSETS.md](../../licenses/ORIGINAL_TOWN_ASSETS.md) に記録。

再生成（リポジトリルート、Python 3 / NumPy / Pillow）:

```powershell
python scripts/generate_detailed_buildings.py
& 'D:/Program Files/Blender Foundation/Blender 4.5/blender.exe' --background --python scripts/review_buildings_blender.py
```

`scripts/generate_commercial_building_assets.ps1` は旧簡易モデル用。新店舗の再生成には上のPythonスクリプトを使うこと。

`artifacts/building_models/town_buildings.blend` に全モデル、テクスチャのパック、プレビュー照明・カメラを保存する。Blender内はZ上・正面+Y。ギャラリー配置の移動はオブジェクト変換であり、メッシュは原点基準のまま。ゲーム用に再書き出す際は配置変換を外し、OBJのY上・正面-Zに戻すこと。

`*_blender_front.png` / `*_blender_back.png` は前後からのCyclesレンダー。これらはアセット単体レビュー用で、ゲーム内スクリーンショットではない。ゲーム本体は明示的な起動指示がある場合のみ起動する。

## 次に補う候補

今回の7種とは別に、車種差（軽自動車・バス・配送トラック）、集合住宅のバルコニーと共用廊下、駅舎・ホーム、街路樹・電柱・バス停を追加すると住宅街・幹線道路・駅前の違いをさらに表現できる。

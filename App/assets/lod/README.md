# 距離別モデル

元モデルの `assets/` 以下のパスを保ち、`.lod1.obj`（中景）と `.lod2.obj`（遠景）を置きます。`manifest.json` は全モデルの対応と三角形数です。

- 元の原点・向き・寸法・材質の対応を維持します。
- 車両の遠景は車体・窓・車輪を少数の箱で表し、無テクスチャの共有材質でまとめて描きます。
- 信号機の灯器名を保持し、LODでも点灯状態を個別に切り替えます。
- 建物は遠方のチャンク内でモデル・材質ごとに結合します。
- 駅・車庫・植生などの手続き生成形状は、実行時の簡略メッシュを使います。もともと最小形状の標識板・箱などはそのまま共有します。

再生成には Blender のバックグラウンド実行で `scripts/build_model_lods.py` を使います。信号の名前付き部品は同スクリプトから `scripts/build_signal_lods.py` を呼び出して生成します。元の高詳細モデルは上書きしません。

`ModelLod` テストは全モデルの寸法・原点・材質参照、通常描画とバッチ描画のGPU読み戻し、12,000台の描画負荷を検証します。
